# BIG-IP fixture: bigip-stock-8.4-3

## Setup

Deploy as described in [stock-tclsh](README.md#stock-tclsh). Recorded input channels: SSH to /usr/bin/tclsh8.4, script on standard input.

Each case file fills the template's `⟦HEX:name⟧` slots with the hexadecimal form of its decoded value and its `⟦PARAM:name⟧` slots with the exact value; the composed bytes are the script that ran.

Used by 30 case file(s).

        set nh_encoded $nh_value
        set nh_encoding binary-scan-tcl-value

    }
}
