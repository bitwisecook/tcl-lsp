# Tcl execution evidence

## Question

> A generic variable operand can be an original plain, qualified, indexed or generated byte object. During ordinary recursive read/write callback suppression, native lookup, callbacks or reporting may change which receiver is selected; command success and a later original-name read are separate observations.

> ordinary recursive read/write callback suppression Which exact completion/result and later original-name observation are returned by the retained scripts?

## Assumptions

Assumptions were not separately recorded in the retained capture.

Recorded scope and limits:

> Only the listed fixed scripts and recorded provider builds; ASCII source character input produces the queried native objects. Binary/decomposed names are generated values, not raw document bytes. BIG-IP, physical object headers, compiler opcode selection and arbitrary observer/alias closure are excluded.

## Script

```tcl-visible
set events {}; set v OLD
proc watch {n k op} {lappend ::events $op; if {$op eq "read"} {uplevel 1 {set v INNER; set v}}}
trace add variable v {read write} watch
set h lappend
set answer [$h v EXTRA]
trace remove variable v {read write} watch
set summary [list $answer [set v] $events]
puts $summary
set summary
```
