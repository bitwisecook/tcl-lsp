# BIG-IP original runtime: dynamic alias

## Question

Does an interpreter alias supply its fixed argument to the target procedure? This constrains alias prefix and call modeling in the LSP, compiler and VM.

## Assumptions

The installed HTTP_REQUEST wrapper evaluated this exact script under catch. Repeated requests can share interpreter state, so later results need not match earlier results; counts are captured log lines, not proof of isolated invocations. The wrapper's errorCode field can reflect existing interpreter state. Results are limited to this context and inputs.

## Script

```tcl-visible
proc __tcl_lsp_probe_2286_r2286_20261006c_one {x} {return "ONE:$x"}
interp alias {} __tcl_lsp_probe_2286_r2286_20261006c_alias {} __tcl_lsp_probe_2286_r2286_20261006c_one FIXED
__tcl_lsp_probe_2286_r2286_20261006c_alias⟦EOF⟧
```
