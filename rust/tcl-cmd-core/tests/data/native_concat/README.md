# Original concat object windows

`probe.c` calls actual `Tcl_ConcatObj` on twenty original input vectors and executes eight original procedure bodies, observing result and literal headers before getters. `jim-probe.c` captures the same twenty direct vectors in the pinned Jim interpreter. Original List children, shared backing, canonical flags, resident allocation, unknown String counts and result identity are independent observations. `manifest.json` records fixed source/header/library/binary hashes and a sixty-second execution budget. `malformed.tcl` checks that successful string concatenation does not imply List validity.

The C8.4 fast path requires pure Lists and copies member references into new backing. C8.5 copies the first canonical nonempty List header; C8.6 and later abandon that path when a later first member starts with `#`. C9 also accepts an actual abstract index-hook List. Jim always builds new backing when every input is a List. Slow C8.5+ results have unknown-count String primaries and allocated bytes, including whitespace-only empty results. C9.1 folded nonzero concat retains its original private result header; earlier compiling releases register its rendered bytes.
