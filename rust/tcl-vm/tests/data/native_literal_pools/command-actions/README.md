# Native command-literal cache actions

The five pinned C interpreters execute four original scripts with data-first or
command-first registration and relative or absolute `head` names. The callback
retains the original operand and observes its primary type before any later
`head` invocation, after deletion, and after fresh registration. The 60 rows
therefore distinguish compile-time priming from runtime getter effects.

C8.5 hides the single-word command literal, copying the current object and
withdrawing its local/global registration. A subsequent data operand has a new
slot. C8.6 and later fresh registration invalidates only the relative command
literal's namespace partition; deletion preserves the descriptor.

`manifest.json` records exact source/header/library/binary/log hashes and native
build commands. For another local pinned source tree, build `probe.c` against
its `generic/tcl.h` and matching static library, then run the resulting binary.
No guest error globals are read while observing these successful operations.
