# Namespace-upvar native controls

Fixed scripts exercise zero pairs, incomplete pairs, missing namespace targets,
and relative current-namespace targets across C Tcl 8.4–9.1 and Jim 0.84.
Each engine table records evaluated completion code and exact result bytes.
C Tcl 8.4 records the unavailable subcommand diagnostic. Jim's helper pads
incomplete pairs and invokes its actual upvar command in the caller context.
The manifest retains original source, header, library, executable and log hashes.
