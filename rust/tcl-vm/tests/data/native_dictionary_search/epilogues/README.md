Compiled C dictionary loops cover normal completion, error, break, continue and return. Native callbacks capture original dictionary reference counts before, during and after each loop. Catch code, result and complete original return-option objects are captured before the callback windows are serialized. The tables contain 35 complete C Tcl 8.5–9.1 executions; C Tcl 8.4 has no native dictionary command, and map requires Tcl 8.6. The matching VM test also requires a DICT_FIRST instruction, so a generic command fallback does not satisfy compiled-search coverage.
