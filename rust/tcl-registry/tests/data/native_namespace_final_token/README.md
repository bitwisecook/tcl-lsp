The native parser exposes the final token counted by a compiler WORD, including variable-name TEXT and nested index components. Namespace binding compilers on C8.6 and later use that final TEXT for their local tail; C8.4 does not inline these commands, and C8.5 requires a compile-known whole word. Empty index TEXT, COMMAND and BS endings retain their distinct native token kinds. The five pinned native parsers execute the identical probe source; the manifest records the source hash and complete outcomes.
