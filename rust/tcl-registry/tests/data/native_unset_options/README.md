Unset options on six original engines
====================================

Eleven original scripts on each of Tcl 8.4, 8.5, 8.6, 9.0, 9.1 and Jim. Each TSV row retains case, source hex, original completion code and original result hex. The result observer is the native binary-scan conversion; tests repeat that same observer rather than claiming raw String storage identity. The probe preserves source/binary SHA, command and the 60-second native budget.

Unknown flags and prefixes are variable names. C accepts only one initial -nocomplain and then optional --; Jim accepts repeated -nocomplain. No arguments or a lone recognised option succeed. Dynamic NUL-bearing option objects retain their native string updater differences; these rows do not grant a compiler-word, cache or object-owner receipt.
