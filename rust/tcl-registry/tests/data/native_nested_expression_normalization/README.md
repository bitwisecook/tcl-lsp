# Nested expression normalization

`source.tcl` compares original nested arithmetic expressions with their direct
forms using native completion codes, results and error metadata. The procedure
name differs between the two arms; the inner expression source remains exact.

Run the script with each pinned Tcl/Jim executable to produce its text file.
The shared C normalization recipe remains conditional on original prepared
source, actual handler identity and unobserved invocation envelopes. Jim has
an independent protocol and does not receive the C recipe from equal results.
