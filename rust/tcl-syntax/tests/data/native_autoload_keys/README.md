# Native library autoload keys

The C probe supplies counted original command objects to the pinned `init.tcl`
`auto_qualify` procedure. Rows retain each result key as resident-byte hex.
The five canonical C releases share these controls: matched separators rebuild
opaque and NUL units through native Unicode, while an unmatched command retains
its original resident bytes. The constructed namespace is supplied separately.

`manifest.json` binds observations to the probe, native header, static library,
executable and `init.tcl`. These observations describe the library's pure key
recipe; they grant no original-object getter authority or loader availability.
Jim's native library capability is measured separately and cannot select a C
recipe.
