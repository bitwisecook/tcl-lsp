# Original local-name lookup

The probe warms the same original `x` object inside a real procedure, invalidates its string without changing `localVarName`, and performs original-object Get or Set. It records string residency and exact `Var` identity before result observation. The five pinned C headers and static libraries are recorded in `manifest.json`.

C8.4 regenerates the name from its owning procedure declarations. C8.5–9.1 preserve absent name strings on successful cache hits. Their trace and missing-value cases abort when the unsupported `localVarName` string updater is reached; `paths.txt` records these as `updater-unavailable`. Both checked ports require a typed host refusal for those paths. The native process status and stderr remain in the manifest.
