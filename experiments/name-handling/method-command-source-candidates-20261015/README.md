# Method command source candidates

These fixed original-provider observations bound two independent source-navigation
purposes. They do not establish an installed call, complete lookup result, method
namespace, entered frame, Native admission or edit permission.

[Relative method lookup](relative-namespace/probe.tcl) records the global helper
before an object-local shadow, then creates that shadow only in the namespace
returned by the original `info object namespace` operation. C Tcl 8.6.18, 9.0.4
and 9.1.0 return `GLOBAL`, then `OBJECT`. A class declared in `::Outer` still uses
`GLOBAL` although a separate `::Outer::helper` returns `OUTER`. Thus the declaration's
outer reporting namespace cannot supply a method namespace. A global header is a
possible source target with unresolved runtime namespace alternatives. C Tcl
8.4.20/8.5.19 and this pinned Jim have no baseline TclOO; their unavailable outputs
are preserved, without an emulation or portability claim.

[Operand effects](operand-effects/probe.tcl) records a literal argument retaining
an `OLD` absolute helper, while a command substitution replaces that helper before
lookup and yields `NEW`. All five original C versions and the pinned Jim show this
result. A known absolute source coordinate therefore does not remove the current
original operand-effects obligation. The compiler's conditional source candidate
is independent from evaluated argv or actual command binding.

Both original manifests, probes and every stdout/stderr channel are byte-identical
copies. Each manifest records process status, actual patchlevel, selected original
library, probe/output hashes and provider/init hashes before and after. No
`tcltest` package is used. Empty stderr files remain explicit. Earlier canonical
proof receipts are not rewritten; these observations grant no Rust or LSP test
acceptance.

Run `python3 replay.py --repository /path/to/tcl-lsp --out /tmp/new-method-observations`
to capture a separate result using byte-identical local providers. The runner
refuses changed providers or probes. It never edits the archived receipts.
