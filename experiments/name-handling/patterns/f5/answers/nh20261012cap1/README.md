# Capability controls: nh20261012cap1

The retained `input.tcl`, `applied.conf`, invocation and raw output files record
the first capability capture. These are separate controls, not portable
corpus/Wiki answers. Exact-context filtering is required because later log
files also contain earlier contexts.

[Capture limits](limitations.md) records incomplete RULE_INIT/procedure fields,
the five iApp implementation markers, zero APL callback markers and traffic
responses confined to unit `0:0`. Missing markers establish no unsupported or
successful lookup answer. Repeated traffic markers lack invocation identities.

This wrapper did not record per-case runtime teardown. The separate
[repair measurement](../nh20261012repair1/README.md) records the later four-unit
check and cleanup of its owned namespace/commands. That observation does not
repair missing original execution evidence. Error metadata availability and
return options are limited as described in `limitations.md`.

`MANIFEST.sha256` seals the retained run files. A file digest identifies bytes;
it does not establish semantic completeness or native execution.
