# Original body-word values

The original five C Tcl releases and pinned Jim executable ran probe.tcl before new Rust expectations. Every valid file invocation exited zero and produced three CASE records. Exact original executable, C init-library, timestamps, source and output hashes are retained in receipt.json; original libraries/providers were unchanged.

A quoted \u0072eturn operand becomes the body value return and transfers control (catch code2), so the later set does not execute. Braced nested literal content remains unchanged and allows the later set (code0/SURVIVED). A dynamic quoted $missing operand errors before body entry (code1); no substitution value may be invented from that spelling. These are word-value/control-transfer observations, not package loading, source file, actual entered namespace or Native compiler proof.
