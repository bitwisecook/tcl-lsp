# How can an original member body supply prefix inventory without body entry?

Status: read-only design, no implementation or new run. The sealed
[diagnostic](../results/composed-callback-consumer/diagnostic-prefix-entry-1/result.json)
measured exact positive/adverse offsets 174/185: full source/config/input and
builder schema pass; the prepared tape has no producer entry and does not
represent either builder. Target resolution/schema guards are unreached. The
four concrete acceptance/withdrawal/currentness assertions remain unchanged.

## Which existing issuer supplies the genuine member region?

`source_registry_words(...).source_script_bodies(&context)` supplies
`OriginalSourceScriptBody` for the selected definer's actual Body operand.
Its `definition_member_region(&context, content_span())` returns
`OriginalSourceDefinitionMemberRegion`. `original_commands()` and
`original_command_words_at(offset)` retain complete original member vectors;
`script_bodies(original)` checks that exact vector's membership before returning
`OriginalSourceDefinitionMemberScriptBody`. That existing type retains the
parent, original member words, body operand ordinal, whole `NativeWord` and
`content_span()`. These are the appropriate source producers. A reported
`MethodDef.body_span`, a freshly interpreted substring or invented method frame
cannot replace them.

`DefinitionBodyGrammar::member_row` returns the existing `MemberRow`, including
`MemberEffect::Callable`, shifted `receiver`, actual `body` operand and
`visibility`. This supports generic member selection through registry data.
`SourceDefinitionMemberBodyPresentation::CallableBlock` is only presentation;
it must not imply a frame or callable implementation. A callable member's
`definition_parent()` does not inherit the enclosing definition vocabulary.

Correction to the preliminary proposal: `OriginalSourceScopedBody` and
`OriginalSourceScopedCommandSchema::select` describe curated `body_scope`
candidate environments. They do not automatically issue a TclOO method receiver
or vocabulary for this input. Their existence is not permission to insert
`my` into a source graph or select an invented Native entry.

## What bounded production change is proposed?

1. **Original definition-member source owner**
   (`registry_invocation/source_scoped_body.rs`): extend the existing
   `OriginalSourceDefinitionMemberScriptBody` with the selected existing
   `MemberRow`/parent-schema correspondence needed by a source inventory.
   Compute it through the retained `DefinitionBodyGrammar` and actual original
   argv, including wrappers/options and declared availability. Expose guarded
   source/context matching on this existing issuer; retain complete original
   body/member geometry. Add no second parser or nominal-class selector.
2. **SourceAdvice inventory owner**
   (`command_binding/source_transition_advice.rs` and its `body_effects.rs` /
   `produced_prefix.rs` modules): use that issuer to traverse only its selected
   original member script on a cloned source `AdviceGraph`. Retain source-only
   prefix inventory via existing `retain_authored_command_prefix`; do not apply
   member-body effects to the enclosing root graph. Keep the real ancestor
   alias transition and producer through `schema_advice`,
   `OriginalSourceCommandTransitionAdvice::lineage` and existing
   `WrittenTransitionApplicability`. Carry the genuine member-body issuer in
   the existing advice/prefix records with explicit source applicability.
3. **Retained source-advice admission owner**, only if required
   (`realm/source_transition_advice.rs` / `source_structure.rs`): join that
   inventory through the same full image/config/input/context, original vector
   and exact producer offset. Preserve conflicting-inventory refusal and
   `matches_source_context`; no reporting-name or fresh-registry fallback.

This repairs the measured missing inventory before proposing any target-schema
change. Rerun the four original controls and inspect the next guard if a target
still refuses. Only an independently selected real source schema can support
`TCLOO_SELF_DISPATCH`; literal spelling or member presentation cannot. No
hardcoded `my`, NativeNameContext, object namespace or scoped command insertion
is proposed. Native handler/body/receiver admission remains independent.

## Which invalidations must remain terminal?

Original builder/target shadows, alias loops/delete/retarget, opaque inherited
writers, dynamic/multiple/expanded words, missing/foreign body issuers and full
source/config/registry/context mismatch must retain their current refusals.
The inventory traversal must preserve inherited uncertainty, bound recursion,
and distinguish genuine callable/member wrapper bodies from inert text.
The existing core `collect_stored_callback_writes` remains the independent
one-hop sink gate: a later unknown `set $destination`, opaque command or nested
second assignment must withdraw the stored selector even if earlier authored
producer metadata remains. Positive/public and separate private-source geometry,
original fixed-word lineage and currentness assertions must all pass without
replacing those adverse inputs or weakening their conditions.

The resulting fact is conditional readonly source geometry. It grants no
future lookup, entered frame, native body/object construction, rename range or
optimisation authority. Earlier interpreter observations and the separate
Logical type-hint failure supply no admission for this proposed source owner.
