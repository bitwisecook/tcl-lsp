# Procedure effect summary consumers

The shared CFG context keys caller-frame effects, formal names, and outer-place writes by Module-issued ProcedureId. Every retained body has its own row. OriginalProcedureSummaryOwners retains the actual immutable Module, original declaration receipts, configured source input, and issued coordinates used to select a summary.

Direct calls use the original host command carrier. Substitution effects use checked_original_lifted_calls_with_metadata_context, including the original expression-role owner. Logical declaration calls use the shared sealed original Logical procedure/operation projection. Native source calls retain their original dispatch point and argument composition. Unavailable or conflicting owners remain opaque. Reporting names and constructed suffixes select no semantic rows.

The per-body global-write closure follows actual selected IDs. Caller-frame summaries compose one original plain-call hop when the callee reaches beyond its caller; unpositioned constructed forwarding remains opaque. Original parameter headers, including raw defaults and order, remain part of source correspondence.

Deferred materialized callback heads select no procedure. Genuine original callback registration-target receipts may contribute the retained declaration body’s MAY writes; future-table uncertainty remains independent. A separately materialized lambda cannot acquire the parent Module’s source call receipts.

Raw Salsa contexts retain the real owner and body IDs. Native and analytical registry-only templates omit the procedure maps and owner only after their independent complete dependency certificates establish the registry-only correspondence. Rebinding retains current source/world/issuer restoration checks. Neither a neutral template nor unavailable ownership grants a callable, runtime frame, Native handler, compiler token, or Normal completion.
