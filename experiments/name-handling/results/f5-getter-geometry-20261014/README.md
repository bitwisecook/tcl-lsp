# F5 XC getter source geometry

The translator reads fixed `f5-irules` source grammar selected by its only public entry points. Original words from one complete command retain their image and configuration. Static command words use the shared Unicode word-value projection; dynamic heads, expanded operands, malformed tails and multiple commands provide no getter advice. Case conversion requires a sole original executable command component; braced brackets remain literal. Class-match advice selects the actual command operand, never a substring elsewhere in the command.

`probe.tcl` and all six stdout/stderr records are original C Tcl 8.4.20, 8.5.19, 8.6.18, 9.0.4, 9.1.0 and latest installed Jim observations with authored mock HTTP/IP getters. The records distinguish static quoted/braced/escaped command names, executable wrappers, literal brackets, bad arity, multiple commands and concatenating suffixes. They establish generic Tcl geometry only. No tcltest was used. They establish no F5/TMM dispatch or availability.

The two software controls retain these geometry distinctions and refusal cases. Existing F5 XC differential assertions are unchanged. Rust compilation and execution are pending the parent's single capture lease. Implementation has only been formatted and apply-checked.
