Replay debugger expression handling uses `whole_var_ref` under its fixed Tcl 9.0 profile and `naming::var_reference_for_style` to select a captured presentation label. Plain input is a literal label query. Complete braced references retain literal dollar bytes, whitespace and unmatched parentheses. Compound or malformed references and substituting array indices decline. Snapshot labels cannot supply namespace/frame/cell identity, array contents or live evaluation. A captured array root is never selected as the value of an element reference.
