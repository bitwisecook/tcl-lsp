# Shared command lookup bases

One `tcl_syntax::naming::command_lookup_bases` primitive supplies current/path/root
order. Logical written-path and constructed-key renderers, authored source
geometry, original C slot projections, immutable compilation snapshots and live
Runtime lookup reuse that order. Source lookup retains its separate alternative
paths and stops before later uncertainty when an earlier binding settles lookup.
Private variable/publication/autoload purposes retain their distinct policies.

`CommandLookupBase` coordinates carry no namespace liveness, binding identity,
closed-world inventory or execution proof. Native adapters keep their physical
namespace traversal and generation checks. `NativeCommandSlotProjection` retains
original C extent and selects path availability: absolute names visit root alone;
C8.4 excludes namespace-path state. Jim's independent flat-key branch remains
separate. A retained current namespace is not replaced by a same-display live one.
