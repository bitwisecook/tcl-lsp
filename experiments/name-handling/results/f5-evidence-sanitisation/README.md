# What remains in the F5 Tcl evidence after lab-detail cleanup?

The retained evidence describes the Tcl questions, exact programs, callback results, completion codes and provider versions. Deleted-lab transport/device identities use explicit placeholders; deployment fixtures use a documentation address. Unrelated virtual-object and hardware/licensing inventories were replaced with omission markers. Browser captures retain probe template selection and callback options; screenshots and their evidence descriptors were removed.

Saved deployment configs and transport source snapshots have changed bytes and are marked sanitised. Historical executed-config hash receipts remain historical observations; they do not claim to hash the sanitised deployment configs. Tcl program bodies and measurement/status/lookup content are preserved. Updated artifact descriptors hash the retained sanitised bytes.

Thirty existing manifests were regenerated over their retained members. Exact affected artifact descriptors were updated without renewing unrelated implementation evidence. Canonical pages use the maintained renderer for the changed records only. Category counts and verification are in [verification.json](verification.json).
