# Tcllib factory name observations

The recorded C Tcl 8.6.18 and unchanged Tcllib package sources distinguish omitted names, literal empty names and literal sigil names for struct graph/tree factories. Omission generates a name; a supplied empty name creates the root empty command. Exact input/output, loaded source and accelerator identities, package versions and original interpreter/init hashes are retained. This is the recorded single-provider package observation, not F5 or cross-version conformance.
