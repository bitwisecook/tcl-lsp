# Existing standalone package-registration owner: selected-result transport

Existing canonical owner row: `Original autoload index filename data` in `docs/design/contracts/shared-utility-contracts-rust.md`. Existing semantics are unchanged: `registration::select_in_plan` requires its actual complete script plan, no fatal tail, a unique exact whole command/token vector, matching complete source bytes/configuration, original static Unicode word values, no expanded head, the supplied Registry and selected authored package-registration descriptor/cardinality/distinct ordinals. Names and versions remain optional source data; unavailable values still decline. This is an explicit standalone index survey, never a replacement for missing supplied-analysis ownership.

The existing private Registration now retains that selected result with its actual SourceImage, complete LexerConfig, RegistrySemanticKey and complete NativeWord vector. `Registration::advertisement` reborrows name/version/body only when the entire current script bytes, config, registry semantic identity and exact token vector agree with every retained original word. Equal name/body spellings at another source site cannot substitute. It neither reparses nor resolves again. Changed full script, full config, store or token positions refuse. The retained NativeWord is lexical geometry, not an entered Native object or policy grant.

The existing standalone ScriptWalker carries the actual result in a private SelectedSurveyRegistration beside the unchanged public Reached callback data. Public scan and scan_with_config retain their signatures, Reached fields, callback order and conditions by stripping only this private facet. parse_pkg_index consumes it and keeps its existing version validation, body ordinal, source collection, filesystem existence, directory fallback, source ordering and symbolic conditions. The public Reached shape remains unchanged. Original-analysis reachability and all five separate release-specific original package-name/loader/control owners remain byte-identical and cannot issue or consume this standalone carrier.

Proposed canonical name-handling addition: A standalone package-index walker transports its already selected source registration rather than reparse the script at every advertisement. Full current image/configuration/word/store correspondence precedes the data projection; conditional reachability, original Native package identities and future loader/lookup/observer/installation obligations remain independent.
