again. Literal spaces/#/?/% are handled once by the actual Path owner before
JSON. Scoped map keys and workspace folder values use the same canonical owner.
Ordinary POSIX ASCII spellings stay identical; Windows drive/UNC and punctuation
now follow the server's actual canonical protocol policy.

patch): POSIX /work/<0xff>.tcl becomes a URI containing %EF%BF%BD, returned as

its own actual supported-platform contract and roundtrip/adversary evidence.
