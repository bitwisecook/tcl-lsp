separates Unavailable from Available(OriginalIrulesWhenInventory). Available
retains the entire OriginalIrulesSourceContext, conditional declarations, and
unavailable original top-level spans. Complete empty therefore means empty
source syntax under this owner, never absence of runtime handlers.

Each declaration retains SourceIrulesEventBody and OriginalRegistryWords. The
join compares the actual event_word NativeWord supplied by lowering to the
actual source argument word under the same image/config/Registry; no event
label joins cards. Missing/ambiguous event body ownership or missing/changed
source vector records an unavailable site. No obligations are filtered or
retagged: detailed vendor cards remain accessible via words().source().

Empty/comment-only sources have no name occurrence. from_analysis admits only
this exact complement of the existing name-ownership requirement: a successful
full lexer result AND the shared parser proves no source commands. Actual
hosted input is additionally mandatory; all existing whole Module/source,
configuration, profile/context/store guards remain. A dynamic or unsupported
command cannot use this empty branch. The inventory also checks lexer failure
independently of successful capture.
