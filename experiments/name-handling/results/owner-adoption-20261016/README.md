Selected source/configuration, retained frame, namespace continuation and Jim
helper/Import controls. [The record](records.json) binds each raw log to its
Git source and selector; the Runtime binary also has an exact test-adapter
overlay. Failed results stay visible. These controls do not supply complete
consumer migration, current repository gates, issue closure or unmeasured
provider semantics. Source and binaries are referenced by revision/hash rather
than copied.
