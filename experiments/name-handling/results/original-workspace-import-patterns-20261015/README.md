# Original namespace import pattern escaping

The fixed probe imports four commands whose counted names contain `*`, `?`, `[`, or a backslash. The escaped patterns import and call their exact original names under C Tcl 8.4–9.1 and the pinned latest-checked Jim interpreter. Each original provider exits zero with no stderr; every IMPORT/CALL row and the executable/init hashes before and after are retained in the manifest. C uses each matching original init.tcl/library; no tcltest is used.

Workspace index pattern classification delegates to the shared Unicode metadata glob grammar. A backslash is not a literal-equality pattern; treating it as an exact key loses the original imported command name. Original source pattern/policy, export, conflict, run-order and alias-lifetime guards remain independent. The fixed Core conformance test checks these readonly import candidates under all six profiles; these shell observations establish no Rust test result, Native lookup or F5 behaviour.
