# Original script command inventories and extension drafts

`original_script_name_query_support` selects a supported external script query grammar from the shell's own version observations. This selection cannot issue Native interpreter, allocation, or command authority.

`original_script_command_inventory_support` returns original callable command operands for an explicit root invocation context. C Tcl enumerates original simple words in each retained namespace context, excludes inherited global fallback by the selected scoped command query, and checks the resulting root-context address. Namespace reports are traversal addresses only; they never become command keys by removing a root marker. An opaque, ambiguous, or unaddressable namespace makes the inventory unavailable as a whole.

Jim uses its original flat root command table query and checks each retained original word with `exists -command`. It does not inherit C namespace traversal or use `namespace which` as an exact-presence substitute. Authored helper namespaces are excluded exactly; similarly named package commands remain included.

`ScriptRootCommandPresencePlan` preserves C's literal qualified namespace prefix and escapes only the simple glob tail. Jim escapes the whole original flat-table key. Both plans retain the original word for autoload and invocation. Queries execute at root; unavailable original transport or unsupported query grammar refuses.

SpecProbe transports only strict UTF-8 checked original root operands. Studio uses these operands as exact authoring draft keys. A scanned C registration literal is independently retained in `c_registration_operands`; `c_publication_context` is `unresolved`. Scanning does not supply the entered namespace, interpreter, API purpose, or original allocation needed to assert a runtime binding. No optional-root descriptor adapter merges these literal operands with reports.

The runtime inventory ABI transports original byte slot components, actual producing namespace and command generation, and an optional root operand checked against the actual root table. Decoded numbers are data, not installed-command receipts. The extension host checks the independent shared root spelling bridge and refuses the whole Unicode catalogue when any row is opaque or has no root operand. It includes visible imports and aliases and detects replacement generations even when printed names agree.
