Script namespace-variable snapshots use the shared Syntax support
`original_namespace_variable_snapshot_support`. Each address retains a namespace
context and the original simple operand. Reads, array access and traces use
`namespace inscope` with explicit global operation heads. Qualified reports are
used only to associate an already selected namespace; they are never parsed to
recover simple operands or Native identities.

The helper declines ambiguous namespace reports, qualified/array-shaped simple
reports and unavailable namespace operations. C8 global fallback rows are
excluded from non-root scope enumeration. Consumers exclude their exact private
namespace subtrees and exact root error variables, retain structured coordinates
as snapshot keys, and keep display labels separate. An unavailable purity
snapshot produces an unsupported result while ordinary command questions and
the completion protocol continue.

Original C8.4–9.1 bracket namespaces, colon-bearing root variables, array keys
and shadowed operation commands have retained source-form controls. The selected original Jim lacks the namespace-children operation;
its purity snapshot remains unavailable. These script addresses supply no
Native namespace generation, variable cell identity or physical object proof.
