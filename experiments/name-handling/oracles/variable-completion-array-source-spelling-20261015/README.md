# Original array-reference insertion controls

The fixed [probe](probe.tcl) seeds separate literal array keys and compares direct
`$arr(index)` source proposals with braced combined `${arr(index)}` proposals.
The [original receipt](manifest.json) retains before/after executable hashes and
all twelve [stdout/stderr streams](archive-index.json) for C Tcl 8.4.20, 8.5.19,
8.6.18, 9.0.4, 9.1.0 and the selected latest Jim oracle. Each process exits zero;
stderr is empty. Executable hashes match the prior
[scalar insertion providers](../variable-completion-source-spelling-20261014/manifest.json).
The [provider comparison](provider-provenance.json) preserves the original
receipt’s path-label limitation without rewriting its bytes.

Direct formatting substitutes literal `$literal` and `[list redirected]` keys
and decodes literal `\x41` on all six providers, reaching a seeded different
element. Braced combined references retain each literal key. Direct insertion
of a closing parenthesis reads the empty element then leaves trailing source;
the braced form retains the complete key. Empty, space and newline keys are
valid on all six providers. Parenthesis handling differs: Jim accepts the fixed
nested index, older C Tcl closes earlier, and C Tcl 9 rejects its unquoted
parenthesis. C Tcl 9 also rejects the fixed raw brace indices. Braced combined
references retain balanced inner braces on C Tcl 9, while C Tcl 8/Jim retain the
fixed unmatched opening brace under their first-close variable grammar.

These are original seeded source interpolation observations. They do not run the
Rust issuer or LSP, establish a current array element or successful general
read, grant Native naming or editing authority, or cover F5. Computed original
index syntax remains distinct from literal key data. Shared
[name contracts](../../../../docs/design/contracts/name-handling.md),
[source owners](../../../../docs/design/contracts/shared-utility-contracts-rust.md)
and the [implementer guide](../../../../docs/design/compiler/name-resolution-implementer-guide.md)
retain current source/input/scope and complete selected grammar independently.

Verify archived bytes with `python3 verify.py`; add `--current-providers` to
compare the executable paths when those original providers are available. The
archive index maps immutable original absolute paths to portable relative files.
No provider needs to be rerun to inspect the original observations.
