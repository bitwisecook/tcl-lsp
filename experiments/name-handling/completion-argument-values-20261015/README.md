# Completion argument values

These fixed original-provider observations correct two fixture contracts; they
are not a production consumer repair or a Rust/LSP acceptance result.

All five original C Tcl versions and pinned Jim return the three literal
arguments `is`, `#`, `comment` for `capture is # comment`. After a semicolon,
`# comment` is a comment and only `is` is captured. A hash in the middle of a
command is an argument, so completion may select its later active argument.

Original C Tcl 8.6.18, 9.0.4 and 9.1.0 accept the complete quoted TclOO selector
`"create"`. The selected source value is `create`; requiring a bare spelling is
not a constructor-validity contract. C Tcl 8.4.20/8.5.19 and pinned Jim have no
baseline TclOO in these providers; their unavailable results remain explicit.
No object namespace, method frame, Native lookup or edit permission follows.

The manifest, probe and every stdout/stderr channel are unchanged original
copies, including empty stderr. The manifest records actual patchlevels,
provider/init and output hashes, selected original libraries and process statuses.
No `tcltest` is used, and no canonical proof receipt is rewritten.

Run `python3 replay.py --repository /path/to/tcl-lsp --out /tmp/new-completion-values`
for a separate observation with identical local providers. The runner refuses
changed probes or providers and never rewrites this archive.
