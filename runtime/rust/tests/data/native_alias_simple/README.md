The probe invokes ordinary `upvar` with original List local-name objects and a raw-NUL scalar local name. The compiled `v` local preserves its original List primary and owns no hash-key object; dynamic locals retain their original key on C8.5 and later. The local-side simple lookup does not install parsed or indexed variable-name caches. All five native libraries execute the same source. `manifest.json` records the source and output hashes.
