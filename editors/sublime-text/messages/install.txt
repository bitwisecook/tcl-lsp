# LSP-Tcl

LSP-Tcl uses Sublime Text's built-in Tcl syntax and snippets. It adds the
tcl-lsp language server for diagnostics, completion, hover, navigation,
formatting, semantic highlighting, code actions, and more.

Install the base LSP package if it is not already installed:

    Command Palette > Package Control: Install Package > LSP

The matching tcl-lsp-server binary is downloaded and checksum-verified on
first use. Configure it under:

    Preferences > Package Settings > LSP > Servers > LSP-Tcl

This package deliberately ships no key bindings.

https://github.com/bitwisecook/tcl-lsp
