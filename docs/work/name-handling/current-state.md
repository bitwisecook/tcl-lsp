## Coordinator rulings awaiting the owner's review, 16 November 2026

Made so sessions were not stalled; each can be overruled.

- **Recovered tail.** The proving walk does not enter commands recovered after an unterminated delimiter. The tail is an editor tier: display facts from written words plus the registry; diagnostics limited to registry-only arity, subcommand and option errors on a single literal bareword head the reached prefix does not rebind; no flow, existence, type or taint diagnostic and no edit-producing consumer there.
- **Bytecode target.** Structured `if` / `while` / static `eval` are lowered under the bytecode target as on `origin/rust`, with the selected compiler's original vector kept on the statement for native emission, instead of teaching the escape summary and both inliners to read a control plan off a call.
- **`return` / `set` selection.** Both halves are on `work`: the `return` half (`a4e9d10e`) and the variable-link half (`92c87dfc`), the second with one named, owned regression (a unit-scope seed, analyser session).
- **Diagnostics.** A variable defined only in the body of a possibly-empty loop is silent; a standalone document's global frame is open except for what the document itself proves; the unreached-site `proc` fallback stays restricted to child-interpreter scripts.
- **Taint.** Hosted metadata may supply getter colours and sanitiser transforms to the taint diagnostic only; each F5 claim has a BIG-IP check.
- **F5.** An unpinned hook is still told 8.4 for F5 profiles (the F5-only rule read as about evaluation); procedure bodies under `f5-iapps` and `f5-tmsh` are entered for a braced body only.
- **Common AOT plan.** Direct-body and constant-store proofs use the token-owned trace check, as the call decision does; a traced procedure or variable must still decline.
- **Summaries.** A binding at the call's execution point decides a global-write summary; fixtures that relied on an installer nobody calls now call it, with one row kept for the as-written shape.
- **Tooling.** Code that asks whether text is one complete command uses the checked segmenter; a supplied analysis input stays exact and the supplier resolves it once for unit and analysis; a directive that cannot be read selects nothing.
- **References.** Callback selectors in unentered method bodies may be reported as read-only reference spans; rename keeps them as a hazard.
- **Server and database (16 November).** Per-body incremental analysis is restored, not the memo tests re-scoped: an edit inside one body re-analyses that body. A position past the end of a line is clamped to the line's length, as LSP 3.17 says. Completion inside `namespace eval` and inside a namespace's procedures writes a global as `$::name`. The IRULE1005/1006 collect-bootstrap quick fix may be offered from conditional advice as a single, not-preferred action, never in fix-all. In a recovered tail, a procedure the reached prefix declares and does not rebind is checked for arity like a registry head. The unassigned `tcl-lsp-db` groups go to the server and database session; a compiler fact goes to its owner with the smallest fixture.
- **Rulings of 17 November, made so the new sessions do not start blocked.**
  - *Stock object types.* A supplied document with no host entry runs in a fresh interpreter that holds only the release's own object types, whose conversion hooks run no script. A list or numeric command over a value of unknown contents therefore does not withdraw the command world there. The premise ends at `load`, at a `package require` the walk cannot prove is script-only, and at any command the walk cannot name. The nineteen tests that state the opposite move to a host-entry fixture and keep their assertion there (`handover-analyser-binding-stock-object-types.patch`).
  - *Receiver methods never called.* An uncalled TclOO, snit or itcl method body is analysed in the end-of-load world for diagnostics and display only: a relative head resolves through the object namespace, then `::oo::Helpers`, then `::`; the entry is refused when the document can put a command into a receiver namespace. No rewrite, fold or rename reads those facts. The class-facts area drafts it; the analyser area reviews it.
  - *File-level W210.* A read at file level of a name nothing earlier bound still warns: the fresh interpreter's global frame holds the startup variables and what the document set. It goes silent only after a command whose effects the walk cannot bound. No wide expectation change.
  - *Recovered-tail procedures.* `7a1d1983` (a procedure declared in the recovered tail recorded through the unreached-site fallback) is reverted if the recovery outline and tail tests stay green without it: the outline comes from written words in `tcl-lsp-core`.
  - *Trace check in the common AOT plan.* The token-owned trace check lands with its two declining tests even though it turns no test green today.
  - *Row-level pack notices.* The loader issues a row subject (a kind that offers no did-you-mean fix); the server does not fall back to the recorded line.
  - *Blocks two levels down in a declaration document.* The shared source structure in `tcl-lsp-core` is the LSP features area's change; the tooling area supplies the fixtures.
  - *Conditional advice with an action.* IRULE1005 and IRULE1006 stay conditional advice and gain an action subject, so the server can offer the bootstrap fix as a single, not-preferred action.
  - *Cross-dialect taint fixtures.* A shell or network sink fed by an iRules getter stays as written: a name catalogued in any dialect keeps its catalogued taint semantics under a Tcl release. A fixture that calls a command no dialect catalogues (`regex::quote`) is corrected to one that exists, with the reason in the test.
  - *Type-table entries.* A qualified scalar (`::ns::x`) and an array element with a literal key (`a(k)`) are places and get entries under the shared naming owner's place identity; a computed element key gets none.
  - *Performance memo and `Rebound`.* A registry-words memo may stay on the finished analysis result if it returns exactly what the recomputation returned. `RealmBinding` does not stop answering `Rebound` for unreached sites as a performance change; an answer change goes through the analyser area with tests.
  - *Per-body incremental analysis* is restored by the analysis-performance area, with the analyser area reviewing how an isolated body carries or reissues its naming receipts.
  - *Semantic tokens* move from the coordinator to the LSP features area.
  - *The naming owner has no session.* `tcl-syntax::naming`, `tcl-lexer` and `xtask` are ruled on by the coordinator. A session that needs a change there makes it as one small separate commit with the tclsh oracle in the test, runs the `tcl-syntax` and `tcl-lexer` suites, `make xtask-gates` and the whole `tcl-compiler` suite against its baseline, and tells the analyser area before pushing.
  - *Backslash in a braced word of hosted source.* A braced, non-expanded word with no backslash-newline is a literal unit whose content is its bytes, backslashes included (tclsh 8.4.20 to 9.1.0 print `4` for `string length {a\\b}`); F5 units follow the 8.4 rule, with a device check added beside #2151. The taint area makes the change in `vendor_source_literal_units`; quoted and bare words with a backslash are not widened.
  - *Pack reference bodies under a live native entry* (owner, 17 November: restore live inlining). The VM's own compile inlines no pack reference body today. A spliced command's native selection site keeps the body's own source image and offset, so native replay cannot find its bytes once the body is rebased into the caller (this refuses even a body the splice renames nothing in); a parameterised splice also renames the body's variables while replay reads the original bytes. The `live-inlining` session restores it in two steps: rebase a spliced command's allocation site onto the caller's image, then make native replay of a spliced command read the renamed variables. The three `codegen_stamps` tests then pass on the live path as written, and the `spliced_bodies` run tests assert whether their site was inlined. Until it lands such a site stays a plain call, never half-admitted. The interim test-only VM entry ruled earlier is withdrawn.
  - *Index files run in a procedure frame that holds `dir`* (#832). C Tcl evaluates a `tclIndex` inside `auto_load_index` and a `pkgIndex.tcl` inside `tclPkgUnknown`, each with a local `dir`. Read as a fresh-interpreter document, the first `$dir` is a proved error and every later entry is unreached, so only the first name was indexed. The caller of an index survey supplies an entry fact (a procedure frame holding `dir`, with the directory as its value when known); the compiler never infers it from a file name, and an ordinary document never gets it. The tk-oo area makes both edits as announced commits; the analyser area may veto the entry fact's design.
  - *`oo::define` on a class the document does not declare.* Alone, the document has no such class (tclsh 8.6.18 to 9.1.0: `::C does not refer to an object`), so `all_classes` holds none on a pinned release (`missing_class_source_cannot_publish_native_definition_stubs` stays as written). With the declaring file sourced first, the members reach that class, so the member changes are recorded in a separate advisory collection of external class contributions, which only the workspace index merges with a document that declares the class (`workspace_index::tests::class_dispatch::*`). No proof consumer reads a contribution directly. The class-facts area implements it; the LSP features area reads it.
  - *A structural assertion with no oracle behind it* (`argument_substitution_mutation_keeps_entered_token_then_deopts_at_next_command`): the entered-command marker on the `string` head push is replaced by the behaviour it guarded, taken from tclsh 8.6 to 9.1: what an in-flight `string equal -nocase [mutate] X` and the next command print when `[mutate]` rebinds the subcommand's target or the ensemble map.
  - *A pin change from inside a native command* is not a host error, and it governs the commands that run after it in the same evaluation. The pin installs at the next command boundary; at that moment the context held by each entered operation of the interpreter is advanced by a sanctioned re-issue (as `authorised_generation` does for observed inputs), and each running function is checked against its manifest under the new context: one that fits carries on compiled, one that does not finishes plain. Only that path may advance a captured context; the command that called `pin_context` finishes under the context it entered with (`a_running_function_is_checked_against_its_manifest_when_the_pin_changes` stands).
  - *Exposures accepted with the stock-object-type rule* (`ae7b3871`: fixed 39). Twelve of the nineteen contradicting tests moved to a host-entry fixture. Seven stayed, because each expectation holds in a fresh interpreter and was green only while the withdrawn world hid a defect elsewhere; they are red, owned, and not counted as new: diagnostics 3 (W210 after a nested unknown command, a false W242), dataflow 1 (a `try` handler inside a `for` body folds to the store before the body: a miscompile, taken first), values 1 (`cu_top_level_eval_body_escapes_via_cu_map`), analysis-performance 2 (`phi_undef_memo` stage budgets, now that the walk reaches every conditional command). An embedding that registers its own native commands (`host_extensible_command_table`) is a host entry and ends the premise.
  - *`global` at level 0 declares nothing new.* In `eval {if 1 {global tg; incr tg}}` at top level, `tg` is the cell a plain top-level variable already is (tclsh 8.5.19 to 9.1.0 print `1 1 0` for the value, `$::tg` and `info level`), so escape analysis tags it Local. `cu_top_level_eval_body_escapes_via_cu_map` asserted Frame only through the withdrawn world's fallback; that one assertion changes, its `::p` half and key assertion stay.
  - *Tests in `tcl-codegen`'s test crate that exercise only compiler code* belong to the compiler area they exercise: `it_3 optimiser_codegen_residual` (23) to dataflow-optimiser, `it_2 compiler_analysis_residual` (28) to values.
  - *A constant into an expression operand (O100).* For a value the walk proves is still a source literal at the read, the numeric reading is a function of its string on every C Tcl release: tclsh 8.4.20 to 9.1.0 print the same answer for `expr {$a + 1}` whatever read the literal first (`format %f`, `format %e`, `lsort -real`, `binary format d`, `string is double`, `incr a 0`). The fold is licensed there, read with the unit's own number grammar (`010` is 8 before Tcl 9 and 10 from it). F5 units stay declined until a device check answers. The lattice's strictness is otherwise unchanged.
  - *Built-in object methods in instance completion.* Every TclOO object answers `destroy` (tclsh 8.6.18 to 9.1.0: `info object methods $d -all` lists it), so instance completion on a release profile offers the family's exported any-object built-ins from the registry's `DefinitionBodyGrammar::builtin_object_methods`, unless the class unexports or deletes one. The three completion tests that pinned a list without `destroy` gain it.
  - *F5 handler and rule-procedure body facts* (a `when` body's stores and reads, a rule's own procedure called from a handler or the rule's top level) are the taint area's, wherever they surface (values witnesses, document symbols, hover); the tooling area keeps the rule loader's declaration parsing.
  - *An overlay whose packs are not installed.* The analysis abstains: a typed `OverlayMiss`, no unit, no findings, and no W123 for a command a pack may be about to define (`an_uninstalled_overlay_yields_no_unit_and_no_findings` stands; `the_analysis_reads_the_packs_once_they_install` asserts the unavailable state before install instead of a W123). tclsh cannot decide this; it is a design decision. Abstaining must not be silent: the server's reason for an unavailable analysis is pinned by a test, or its absence comes back to the coordinator.
