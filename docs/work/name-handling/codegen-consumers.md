## Completion rule

Every remaining procedure/body semantic map above belongs to the #1778 ID
migration, and must retain all actual declaration Statements and analysis bodies
on generic fallback. Private candidate generation and normalization must be
replaced or purpose-bounded by the existing naming/selection owner. Arrays,
scalar local slots, CFG block names, ELF labels and Registry descriptor IDs are
separate representations; don't force them through Tcl command parsing.

The initial broad compiler match inventory is
`/tmp/codegen-1778-consumer-paths.txt`; its remaining analyser/optimizer/tooling
matches require per-callsite dispositions before any entire-codebase completion
claim. This audit reconciles actual target entry points and representative map
owners; it does not declare that all those additional consumers are done.
