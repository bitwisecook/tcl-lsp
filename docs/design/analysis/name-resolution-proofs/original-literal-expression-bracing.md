# naming.refactor.original-literal-expression-bracing

Kind: `implementation-contract`

## Problem statement

Quoting and bracing can change word evaluation, expression substitution, function lookup and compiler preparation. A selected expr spelling or a pure-looking source string alone cannot permit the rewrite, especially after handler, observer or Registry changes.

## Question

When may a sole whole root-source literal expression operand be braced under independently selected finite native evaluation, unchanged original argv/handler/compiler effects and closed source reflection?

## Conclusion

The issuer authenticates the exact source binding, complete two-word original vector, full source/channel/configuration, actual unchanged stock expression handler, quiet observer/runtime boundaries and current Registry semantic key. Independent compiler-name effect closure must hold without borrowing opcode admission. The static unexpanded operand has a checked native expression tree with no variable, script or function evaluation, and the independently selected constant evaluation policy must yield a finite normal value. A separately authored braced word is parsed and decoded under the same grammar to reproduce the counted operand bytes. Source reflection is closed only for a sole whole root/global command in the original source image; procedure bodies and any later source command are refused independently of argv equality. Core rechecks complete source and Registry before changing that one original operand span. Division errors, substitution, functions, malformed or multiple operands, expansion, source-defined handlers, observation, unknown state and stale ownership refuse. The permission supplies a bounded source replacement, not a general Normal, physical object, compiler-admission, insertion or expression-equivalence capability.

## Scope

Current Rust bounded literal bracing for a sole complete root-source command under independently selected C8.4–9.1 and Jim084 grammar/evaluation policy. Fixed assertions separate finite arithmetic from division errors and reject procedure bodies or later source observers even when arithmetic argv agree. All seven native providers are not-tested for this implementation contract. Existing native error-context and body/source-observer outputs are independent empirical questions; no passing Rust receipt is attached.
