# naming.core.original-source-instance-completion

Kind: `implementation-contract`

## Problem statement

Method and property completion can reconstruct a class from final reporting object/handle maps, borrow a captured selector as a later written argument, or let a conditional source construction imply runtime receiver identity or rename safety.

## Question

How do primary/fuzzy method candidates and property options retain genuine original source instance ancestry, effective argv and exact cursor geometry while keeping current receiver identity and Logical compatibility independent?

## Conclusion

InstanceCompletionSource retains either the complete OriginalSourceClassInstanceWords receipt and its canonical original class declaration or an independently positioned current receiver with its genuine whole written vector. Full source/configuration/context correspondence remains mandatory. Conditional named receivers retain original moves and aliases; anonymous symbolic handles keep genuine setter/constructor ancestry and no fabricated slot. Effective argument selectors retain their authentic producer/policy domain. A captured method selector supplies no later written replacement extent. Method position requires the actual complete selector or selected intra-command whitespace/continuation gap; later arguments, bare newlines, semicolons, comments and unknown expansions refuse. Primary and fuzzy method candidates share the same source declaration ledger; property options share effective selector/argument ordinals. A narrow completion spelling replacement uses only the genuine complete written selector under its independent source-value/name edit checks. Source candidates do not establish a member rename or runtime identity. Stale/foreign input, terminal result mutations, missing canonical class and detached reporting maps refuse. Positively retained Logical compatibility keeps its selected class and instance/class bucket together. Native rename hazards narrow only through an independently positioned actual receiver; a source candidate or donated class report cannot remove a hazard. No successful construction, stored handle, cell, allocation, lifetime, entered frame, Native execution or Normal completion follows.
