# naming.editor.original-instance-member-rename-plans

Kind: `implementation-contract`

## Problem statement

Method reporting maps cannot establish the current method allocation, default visibility, builtin roster or every selector affected by a member rename. Partial source edits can cross a different table, callback or independently owned document.

## Question

Which actual instance-table roster, canonical selectors, current owner and static source-container obligations close one atomic ordinary source member rename?

## Conclusion

The member planner requires one independently current ordinary source class, its actual Instance method entry and a complete shared instance-method roster including AnyObject builtins. It preserves the selected grammar default visibility rule and validates the replacement against the complete roster. Every affected call must carry the actual canonical receiver/selector entry, and whole-source traversal must close body coverage and direct static source containers before the declaration and calls are edited together. Prepare consumes the same owner-bound unchanged-tail plan. Overrides, later configuration, ClassObject and own-object tables, generated links, future callbacks, ambiguous or stale independent owners and unavailable coverage remain terminal. The plan supplies bounded source editor replacements, not native dispatch, runtime method installation or arbitrary reflection equivalence. Body coverage requires the actual canonical worker NativeWord and its shared content span. NativeCompilerWords formed content must equal the result of the independently selected source-channel literal ingress at that same span; Document Unicode and CRLF do not rely on raw source/native byte equality. Cooked source content or an absent worker word remains unavailable.

## Scope

Current Core ordinary instance-member rename planner and Server atomic current-owner transport. Fixed controls cover opaque selectors and report-map clearing, builtin/default visibility/family blockers and independent workspace owner/collision checks. Native transformed-program behavior and Rust test execution are not claimed.
