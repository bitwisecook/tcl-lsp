## Conclusion

Runtime closed lookup and definite invocation remain unchanged; no entered receiver, physical caller cell, Native compilation, Normal completion, successful alias/store or edit authority follows. Foreign body text is refused by the shared source scanner. Receiver declaration direct-formal inputs may follow aliases only with an independently retained original prefix proving every alias targets the immediate caller frame. Same-frame/unknown aliases or retargeting to them, formal writes, unknown prefixes, observers and operand effects remain terminal. Shared scalar-slot and unchanged incoming-value proofs still apply; no successful alias, read, current caller address or Normal grant. The immediate-caller prefix also requires a retained literal target subject: a computed target or level cannot discharge unresolved alias selection even when the authored local destination is known. A declared receiver always requires its independently retained original conditional alias prefix, including when enumerable alias maps are empty. An unresolved dynamic alias can withdraw that prefix without installing a visible alias, so empty maps cannot discharge caller-alias uncertainty.
