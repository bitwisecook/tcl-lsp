# naming.source.original-structured-script-timing

Kind: `implementation-contract`

## Problem statement

Requiring literal Strings for every script/prefix operand loses selected callback positions when payload values are unknown. Guessing selectors or effective cardinality instead can invent executable roles, and reference-only operands must not become source execution positions.

## Question

How does the selected original descriptor preserve script/prefix positions and timing over structured unknown payloads while requiring known selectors and exact effective count?

## Conclusion

Structured timing and prefix positions share the selected descriptor, option grammar and actual argument/cardinality owners. Consumers can retain unknown ordinary values without guessing spellings or granting callback execution, installed handlers, Normal completion, frames or editing authority. The selected timing owner receives genuine InvocationArguments rather than requiring every payload to be a literal String. CommandPrefixArguments retains optional explicitly supplied compatibility spellings; actual-arguments ingress has none. Count-only authored resolvers require exact argv count, and selector-dependent resolvers inspect only known selectors. Unknown callback payloads retain their selected positions and arities; reference-only trace removal excludes execution, unknown trace selectors and expanded cardinality refuse. Pack timing thunks preserve Dynamic/Expanded/Literal kinds to the guest. A separate selected ListArguments descriptor supplies only a finite ASCII non-NUL Tcl list value through the shared list serializer; unknown/non-ASCII/raw-NUL/expanded elements and non-C dialects refuse. This is readonly source grammar, never native object construction or result/header correspondence. Source consumers retain the original value producer and selected script-timing applicability. They can resolve a known structured operand without placeholder String values, callback execution, frames, Normal completion or edit authority. Within a positively owned C child-source snapshot, the shared original singleton command-substitution geometry plus a visible selected ListArguments descriptor can retain a finite ASCII list value for readonly role selection. The capsule retains the original operand, complete list-producer vector and full input; it supplies no native result object. Genuine uplevel [list source ...] inputs, quoted file-name element boundaries and nested static list producers resolve through the same FrameLevel role grammar before fallback. Dynamic head, non-list producer, known list shadow, inert set data, reference-only trace removal and unknown trace selector controls retain no W129 conclusion. Executable positions come solely from authored_source_script_arguments, preserving ReferenceOnly exclusion and unknown callback payloads. The selected source-script position query projects both authored Body and command-prefix positions from the same selected descriptors and structured timing owner. ReferenceOnly positions are excluded. The separately named Logical query receives positively retained Logical role positions and retains Native frame/effect uncertainty. Generic executable source-script positions retain LambdaLiteral for its own grammar. A separately named plain-script projection accepts Body and CommandPrefix positions from the same selected role, option and prefix descriptors; LambdaLiteral and ReferenceOnly stay excluded. Unknown type selectors and expanded cardinality keep their existing refusals.

## Scope

Three marked Rust controls compare selected trace add variable/execution prefixes and ReferenceOnly remove under five C source profiles, retaining unknown target/callback values while refusing unknown selector and expanded count. A selected ListArguments descriptor serializes independently known finite ASCII elements, preserving spaces and leading hash quoting; dynamic, expanded, raw-NUL and non-ASCII elements refuse. A pack guest observes a true Dynamic kind and supplies Deferred timing; Expanded and a literal empty value remain distinct. These are descriptor/guest source-purpose controls, without native provider execution or result object correspondence.
