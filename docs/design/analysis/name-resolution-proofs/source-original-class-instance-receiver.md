Unknown earlier mutation remains conditional. Full source/configuration/context and canonical manufacturer visibility are rechecked; private, overriding and provider type-method routes refuse. Empty/NUL refusal and independently bounded Logical geometry remain. Registry schema selectors and mandatory registered factory-name layouts do not inherit this separate Native class-instance naming purpose.
