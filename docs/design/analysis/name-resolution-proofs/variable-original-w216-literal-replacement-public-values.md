# naming.variable.original-w216-literal-replacement-public-values

Kind: `native-observation`

## Problem statement

A proposed source spelling for an array element must retain literal root characters and original index substitution, while an inserted stock ::set head is an independent premise. Value context and entire-script command dispatch need distinct public observations.

## Question

What exact public values do the eight fixed proposed literal-root/index spellings produce under stock ::set in original value context, how does a replaced ::set change the value, and what do the independent whole-script dispatch controls report?

## Conclusion

All six providers report code0/equality1/info-exists1 and exact VALUE_label for the eight value-context originals: dollar, quote, brackets, backslash, literal Unicode, quoted_index, nested_command and split_root. The independent replaced_set value is CHANGED on all six. The other whole-script originals use the proposed substitution as the entire script and all eight rows catch invalid command name VALUE_label with equality0 and info-exists1; their replaced_set row retains each provider's exact missing-local or invalid-CHANGED diagnostic. Those whole-script rows provide no positive value comparison. All twelve fresh CLI processes exit0 with empty stderr. These are fixed public stock-head/index/value examples, not a general editor safe-transform, unwritten ::set availability, current-cell completeness, opaque native name key, header pointer or compiler-entry grant.

## Scope

Two unchanged UTF-8 LF inputs preserve a literal U+00E9 root, literal split-line root and ASCII escaped proposals. Each original source context, complete source/request/launcher/stdout/stderr/receipt and required executable/archive/header/build/source pins remains exact. Stock-head public values and the authored known replacement remain separate premises from the seven-not-tested W216 source renderer contract. BIG-IP and executed Rust assertions are not tested. Two Compiler source/archive controls require the eight genuine proposed strings to occur in the untouched executed value-context source and retain all nine whole public rows plus empty stderr for every provider. Their archive association is not a native rerun, actual current stock-head receipt, private identity or editor safe-edit permission.
