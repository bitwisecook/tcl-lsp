# naming.refactor.original-datagroup-variable-subject

Kind: `implementation-contract`

## Problem statement

A switch subject reporting label can erase its original substitution syntax or classify inert, compound or array data as a scalar variable. Data-group extraction advice and MCP syntax suggestions need the same original scalar subject, selected case layout and completed literal values independently of edit or runtime authority.

## Question

When does a selected switch operand contain exactly one genuine original scalar substitution, and how do Core extraction advice and actual-analysis MCP suggestions retain its syntax and literal case values under the same grammar?

## Conclusion

OriginalScalarVariableSubject requires exactly one original executable Variable component with no separate index. Shared whole_var_ref, variable_reference_root_bytes and closed-element partition preserve literal scalar parentheses and selected brace/Unicode rules. The complete original subject spelling, including quote wrappers, remains the proposed operand; a reporting root is not emitted as bare source. Selected exact, case-sensitive Registry case layout retains authentic effective alias-bound operands and literal pattern/body values. Actual-analysis MCP traversal uses SourceSyntaxStructure and the same full input/image/Realm/config; known replacement or missing/stale ownership withdraws suggestions. Explicit standalone Core authoring remains separate. These source/API controls establish source classification and generated lexical completeness only, with independent edit eligibility and no native read or runtime equivalence.

## Scope

Six marked source/API controls cover complete scalar spelling, literal dollars/backslashes, spaces/quotes, Unicode and selected first-close versus nested brace grammar; inert/compound/array refusal; literal case values; authentic selected aliases and bound argv; known shadows and missing/stale/config withdrawal. Source suggestions retain original syntax but supply neither a Native cell/current read, command identity, entered body/frame, successful class operation nor a general edit permission. Generated source completeness under the same grammar and structural edit/record assertions are independent of BIG-IP data-group execution or runtime equivalence. All seven external providers are not tested for this implementation contract. OriginalExactCaseSource retains the shared selected exact/case-sensitive layout and an arbitrary genuine original subject word before the independent scalar projection. Data-group advice still requires the exactly-one-scalar predicate and keeps its complete original syntax; a general literal, compound or array subject cannot borrow that scalar classification.
