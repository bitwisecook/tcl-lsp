## Problem statement

Reporting procedure/class maps cannot identify an opaque original declaration or establish that its renamed spelling still selects the same command. Partial edits can also miss an earlier occupied lookup cell, an independent document, a callback prefix or an unrepresented executable region.

## Question

Which independently current declaration, lookup, completed-world occupancy and static source-container obligations must close before offering or emitting one atomic procedure/class command rename?

## Conclusion

The planner revalidates every independent URI, complete source/configuration and completed Normal source world, then reselects the exact procedure/class declaration allocation and unchanged publication. Literal API replacement units use the retained native ingress and command-component recipe. Canonical cell occupancy and every original ordered lookup alternative must admit the same destination. Complete actual source traversal requires declared transition knowledge and closes selected regions and direct references; name links, observers, reflection, callbacks, unknown command-data roles, unclosed regions and readonly expression identifiers refuse. Each declaration and direct call requires its own static original source container; edits are emitted together only after all obligations close and overlap checks pass. Prepare validates the same unchanged-tail plan before projecting genuine source geometry. Missing Native member-family edit ownership is terminal and cannot enter reporting-string override rename. The plan supplies editor replacements, not native insertion, allocation, execution, Normal completion or arbitrary reflection equivalence.

## Scope

Fixed controls exercise direct static procedures in selected C/Jim models, opaque report-map counterfactuals, duplicated/stale owners, baseline and peer publication collisions, unknown regions, aliases, callback/reflection/math refusals, and Native member-family refusal. No native transformed-program experiment or passing Rust execution receipt is attached.
