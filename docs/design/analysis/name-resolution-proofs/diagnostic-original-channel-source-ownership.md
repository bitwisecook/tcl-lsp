# naming.diagnostic.original-channel-source-ownership

Kind: `implementation-contract`

## Problem statement

A written argv label, raw String reconstruction or reporting declaration can assign a channel role to the wrong value or source anchor. A complete written scalar substitution must also retain its actual read identity rather than resolve a display name into an unrelated SSA cell.

## Question

How do channel diagnostics retain selected source roles, genuine original values and written anchors, and the actual scalar read identity without proving channel existence or runtime effects?

## Conclusion

channel_arguments selects the original Registry schema or immutable declared contract through the retained whole token vector and complete actual analysis/context. Complete effective roles map only to genuine written whole words; captured prefixes and unproved optional-selector layouts cannot acquire an anchor. Original literal values remain distinct from scalar substitutions, interpolation and array indices. scalar_variable_reference retains the whole original scalar part span and a presentation label, while emit_channel_diagnostics matches the actual token access at that span and asks read_reference_at for its original SourceSite/spelling and the selected read version. Display names do not select a cell. Typed RegistrySource or DeclaredSource ChannelArgument purpose survives Core transport independently of messages. No current channel, native handler, successful read/write, entered frame or rewrite equivalence follows.

## Scope

Two marked Rust ownership controls retain complete original source roles, values and written extents. Six C/Jim source contexts keep a braced literal dollar as data, refuse an unknown optional-selector layout, retain a selected whole scalar operand without a literal value, block genuine builtin shadow and preserve a canonical block-framed declaration-supplied Channel role while rejecting its orphan form. A C8.6 source control retains exact whole-word W126 anchors and typed ChannelArgument for stock and moved heads, including braced and literal-dollar words, while excluding standard-channel literals, message-only puts, captured alias prefixes and known shadow. Source type advice remains separate from native channel allocation/existence and observed Tcl/Jim/BIG-IP effects. Interpolation, array-index substitutions, expanded/captured operands and inconsistent actual read identities refuse the scalar projection.
