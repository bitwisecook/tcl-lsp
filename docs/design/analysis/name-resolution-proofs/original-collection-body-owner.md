# naming.source.original-collection-body-owner

Kind: `implementation-contract`

## Problem statement

Conditional collection-body analysis needs the complete original child carrier and actual CU/function owner. Reconstructing source, namespace, grammar or inherited-frame presence from body text or a report label can turn withdrawn ownership into an empty inventory, donate event assumptions or lose genuine class spellings.

## Question

Which actual CU/function/source facts authenticate conditional original child-body CFG and lattice analysis, and which source/configuration/class-roster/entry mismatches must withdraw that analysis?

## Conclusion

The actual CompilationUnit factory checks full original source/input/config/store and retained Module/function ownership, then selects the child only through original parent tokens and argument ordinal. The independently retained child namespace and NestedScript input/config feed conditional CFG/lattice facts. Descriptive class spellings come from the configured signature producer and remain guarded by complete semantic source correspondence; every genuine CU calls the full-owner guarded selected signature producer once, independent of lexical spelling, while conditional source refusals remain explicit. Inherited-frame places start MayBound, with genuine local store/unset refinements and an Unknown-frame fallback for empty source. Missing, foreign or changed ownership remains unavailable rather than an empty pairing inventory. Eleven finite software controls are linked definitions without an attached assertion result; all seven external executions are not tested.

## Scope

Current Rust source/API contract in tcl-compiler and actual tcl-lsp-db source-owner propagation, authentic module/test registrations and eleven unexecuted software controls. Whole original CU/Module/FU/source/Registry input/configuration, retained original vector/ordinal, child namespace and descriptive immutable class roster remain required. Positively tagged standalone ingress is explicit and separate. Primary and secondary analyses share descriptive facts only; source labels and semantic Eq supply no allocation identity. Conditional mutation/trace/deferred-write and existence facts carry no enclosing event descriptor, connection-entry names, parameter constants, physical caller state, Native compiler receipt, worker/body entry, Normal completion, variable/store permission or BIG-IP/TMM grant. Dynamic-definer completeness, runtime class identity and the cost of always invoking the selected signature producer are unproved.
