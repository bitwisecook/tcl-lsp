# naming.source.original-registry-header-advice

Kind: `implementation-contract`

## Problem statement

An uncalled original procedure body can retain an exact declaration layout while its runtime handler and value-read completion remain unknown. Execution-only metadata queries would lose readonly signatures, but using reporting command text would invent lookup ownership.

## Question

Which genuine source owner may supply conditional Registry command words for readonly header advice?

## Conclusion

The complete original word vector authenticates the query. A unanimous retained execution envelope is preferred; otherwise the existing closed original declaration-layout issuer supplies only conditional metadata. Execution, Normal, stores and compiler admission are unchanged.

## Scope

Readonly Registry metadata under a matching complete original word vector/configuration and an independently closed declaration point. Changed original syntax, missing ownership and source-defined handler shadowing cannot inherit the stock Registry shape.
