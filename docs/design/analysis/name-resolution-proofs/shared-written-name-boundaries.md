# naming.grammar.shared-written-name-boundaries

Kind: `implementation-contract`

## Problem statement

Core, Registry, syntax and lexer consumers can repeat colon-boundary scans while selecting different counted, CString, Jim and bare-variable inputs. A shared byte span must preserve complete written separator runs without substituting a generic QName projection for the selected input, result or runtime identity owner.

## Question

How do actual counted qualifier/tail and nested ASCII variable consumers share the canonical boundary workers while retaining independent original C/Jim input/result contracts and selected Registry stock-function identity?

## Conclusion

written_separator_extent derives the complete final written separator from qualifier_component_extents, and written_command_tail reuses that span. Core neutral and Registry counted qualifier/tail adapters share these queries. Native C qualifier reporting keeps its original CString selection before the query; Jim keeps its separate last-colon branch and original-object result roles. The array-index scanner delegates its existing ASCII bare-variable door to the core-types worker without changing selected braced/array styles. VM math dispatch uses the Registry direct-global function descriptor after actual stock identity selection and refuses an unavailable descriptor through the typed Host boundary. Three fixed software control definitions exercise counted spans/Core adapters/actual nested array scanning. No software assertion or provider execution outcome is attached.

## Scope

Current pure counted written span/tail API and finite seven-leaf consumer relocation, with three unexecuted fixed software controls. Complete separator runs, lone colons, empty/trailing forms, Unicode and embedded NUL are source/counting examples only. Original C CString extent and Jim primitive/result-object behavior keep their separate owners; no Native language/name-key/namespace/source-edit/dispatch/reference or callback chronology is inferred. Existing Native proofs remain independently scoped and unchanged.
