# naming.entered-child-source-completion

Kind: `native-observation`

## Problem statement

A known child result may still cross a script or procedure completion boundary. Borrowing produced bytes as a normal source completion can conceal an Error, Return or caught failure.

## Question

How do the eight exact child-producing source scripts settle command substitution, catch, subst, expr, conditional and loop completion?

## Conclusion

The48 retained rows keep exact sourcehex, outer completion and resulthex for eight original scripts on six providers. Inner catches settle their own errors as stated by the source; these result observations do not authenticate private object headers or a different child compiler.

## Scope

ASCII probe.tcl, captured actual C patchlevels and Jim0.84-9-g5bac7c9; exact eight-case TSVs. No BIG-IP measurement.
