# naming.source.original-declared-command-word-contract

Kind: `implementation-contract`

## Problem statement

Document and workspace stubs retain roles and arity but no command implementation. Spelling-based builtin schema selection can donate undeclared expression or body traits and bypass known source replacements.

## Question

Can source consumers retain the genuine complete invocation and declared contract without selecting builtin or runtime implementation facts?

## Conclusion

A separate sealed OriginalDeclaredCommandWords receipt joins the immutable authored contract and provenance to the exact resolved source input, original whole invocation and canonical source declaration selection. The shared declaration owner projects optional-slot roles and finite arity, with direct-written ordinals and explicit applicability obligations. Declared source diagnostics retain their own finite signature and optional-slot expression roles, with concatenation disabled. Original whole written extents, declared purpose, provenance and applicability obligations survive typed Compiler/Core transport independently of message wording. Review proposals establish no builtin traits, runtime target or Native handler. Deferred Logical procedure and static namespace bodies retain sealed whole-source scope, frame recipes and ancestry through the same body/command owners. Genuine current document/workspace contracts enter full, chunked, incremental and standalone document realms through one immutable declaration carrier. Genuine authored declaration supplied optional slots contribute only their own VarRead/VarWrite purposes, with no builtin frame/alias traits or schema donation. W212 retains a distinct typed Declared VariableName subject; W216 recognises the legitimate indirect array-name spelling from the same source role receipt. Actual proc shadows, missing declared roles and expansions decline. Core transport preserves purpose/provenance/original ordinal independently of diagnostic wording and fixes.

## Scope

Positioned Native declaration advice and independently selected Native/Logical authored root source assistance. Deferred Logical procedure and static NamespaceEval bodies retain their genuine whole source body/name, actual resolved input and parent ancestry. Shared ASCII source geometry preserves constructed namespace components, qualified and nested procedure scope, namespace scope and current-before-global declaration candidates; it supplies no namespace existence or runtime frame. Full source/config/context and complete direct-written original words are required. Known procedure replacement, move/delete barriers, dynamic heads, expansion, inserted alias operands, computed namespace names, unsupported or unowned body scopes and foreign input decline. Unknown earlier effects and deferred body applicability remain explicit obligations. No builtin concatenation/effects, actual target, Native entry, entered frame, Normal, successful publication or edit permission follows. Native physical body scope and unknown TclOO private namespace remain separate owners. Genuine document/workspace contracts enter every document realm through the immutable declaration carrier, preserving supplied-entry facts and current document precedence. The declared diagnostic purpose and provenance remain independent of builtin schema, messages and review proposals; these linked assertions supply no native execution observation. Declared source contract applicability only; no installed definition/builtin implementation, target cell, handler, activation, success or edit authority. Provider observations and Rust execution remain independent. Inline document contracts must be inside the canonical stubs-begin/stubs-end block; orphan lines supply no declaration.
