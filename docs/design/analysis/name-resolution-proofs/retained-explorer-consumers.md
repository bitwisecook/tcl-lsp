# naming.source.retained-explorer-consumers

Kind: `implementation-contract`

## Problem statement

An Explorer result retains a CompilationUnit, original Module source and complete metadata. Reconstructing a registry or parser from its display dialect label can replace those owners; collapsing an unavailable retained view into an empty array presents a completed analysis that did not occur.

## Question

Do the selected Explorer event-order, optimiser, statistics, annotation and rewritten-source views retain the actual Module full source/input/configuration/command store, and do missing, foreign or changed owners withdraw those views while presentation distinguishes unavailable from completed empty rows?

## Conclusion

The inspected common retained_explorer_source query checks exact result/CU/Module image correspondence, retained positioned realm, original registry, complete resolved input and full lexer configuration. Its selected consumers query the actual CompilationUnit and use explicit local parser purpose. Missing or mismatched owners return unavailable data; independently rewritten source receives its own source producer under supplied complete metadata. Wire/render consumers retain null or absent fields separately from completed arrays, including empty arrays, and preserve independent warning rows.

## Scope

Current inspected Rust and shipped JavaScript/TypeScript source plus eight genuine unexecuted software control definitions: six C/Jim known-environment model ingresses, custom BOM/store selection, thirteen owner changes, independent rewritten source, two Rust view-tree controls and one Node DOM-stand-in integration definition. The common query covers only the listed retained consumers. Other Explorer analyses and standalone fresh-source APIs keep their own independent guards; no exhaustive all-consumer closure is asserted. No matching successful own image, executable inventory, assertion receipt, browser, external C/Jim/BIG-IP execution, Native admission, source-edit permission or measured performance result is attached.
