# naming.core.original-registry-source-hover

Kind: `implementation-contract`

## Problem statement

Nominal registry lookups can show builtin, subcommand or option docs for data operands or known custom handlers; caller metadata and reporting scoped regions can replace actual retained owners. Enumerating raw CommandSpec.subcommands can advertise operations outside the document’s actual version or provider context, including Tcl 8.6 info operations in a Tcl 8.4 document.

## Question

How can hover preserve current whole-source owners and exact command or operand positions while distinguishing conditional source documentation from runtime identity?

## Conclusion

These docs issue no runtime availability, entered frame, cell, Normal, insertion or edit permission. No source line-prefix parser or reporting-name metadata relookup supplies a source card, and no runtime lookup, compiler, Normal, naming publication or edit authority follows. ## Scope

Ordinary data, fake reporting regions and foreign contexts cannot supply command identity. An exact excluded source option remains documentable with an explicit availability annotation, independently of handler acceptance. The command head remains selected through its exact ASCII source presentation. Raw zero keeps its counted-byte facet, dynamic/expanded inputs keep their uncertainty, and cooked quoted bodies cannot donate original script geometry. These advisory argument bytes are not a Native value, name policy, runtime lookup, entered body or edit capability. A Native-source root card requires a separate readonly disposition selected before the caller-navigation branch. The existing original command owner attaches exact read receipts; the actual original variable root's mapped source span must select one unique read. Unqualified source names require a nonempty original read-context set whose every alternative retains a global frame and root namespace geometry; the joined compatibility context cannot establish unanimity. An absolute root name retains its own selected input qualification, independently of local frame layout. A missing/conflicted read, unavailable source, declaration, non-root/local name or array-index cursor supplies no card. This disposition yields no declaration or reference set and supplies no runtime read success, cell, handler or edit permission.

A descriptor written after an unknown call can itself have only conditional source applicability. Its source declaration card does not establish that its mutation ran. Such following Registry cards retain explicit unresolved-availability wording; independently retained custom/deletion barriers from before the unknown call still withdraw nominal documentation.
