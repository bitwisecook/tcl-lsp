# naming.editor.original-indexed-source-location

Kind: `implementation-contract`

## Problem statement

An indexed original namespace or variable occurrence can retain correct byte identity while its foreign document source or grammar changes. Turning its old span into a current location, or counting it for hover, requires independently current source facts; equal display labels and valid numeric bounds cannot establish them.

## Question

Does the readonly indexed-source carrier require complete current document source/configuration, selected Registry identity and exact original semantic fact membership before supplying a location or count?

## Conclusion

The carrier retains its independent URI, complete source image/channel, scanner configuration, structural Registry semantic key, advice mode and original variable, namespace, canonical procedure/class declaration, hosted declaration or selected Registry symbol fact. Validation requires the same complete current source context and actual current original fact, declaration identity or selected role; stale source, changed full configuration or Registry, missing fact or variable conflict withdraws the span. Namespace semantic membership ignores optional presentation labels and source_span. Implicit-parent spans use the independently retained declaring descendant and existing original prefix geometry only after the current fact is revalidated. Server locations and hover counts use this same validation after reading each owning document. The carrier supplies source assistance, with no lookup, native cell, namespace existence, Normal completion or edit permission. Constructors retain candidate facts; declaration and implicit-parent getters classify them only. A consumer must obtain validated_span before publishing a location or count. Workspace symbol projection requires independently current full source context before selecting original indexed identity or positively retained Logical report advice. Missing input, stale configuration and removed/reused document context withdraw both branches even when report tables remain populated.

## Scope

Core and Server readonly source facts for Native variable/namespace and readonly declaration/Registry-symbol location and count consumers, including hosted source cards, including independent equal-source URI owners, opaque source inputs, cleared or colliding reports, foreign facts, full-source/configuration/Registry changes and current implicit-parent geometry. A genuine parent query selects an ancestor of the separately retained declaring descendant. The caller retains URI-to-document ownership through reads and rendering. Rust execution results are separate receipts; no guest result is attached.
