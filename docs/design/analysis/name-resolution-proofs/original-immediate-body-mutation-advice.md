# naming.source.original-immediate-body-mutation-advice

Kind: `implementation-contract`

## Problem statement

An authored alias can select a script-body grammar even when earlier source prevents a completed command world. Blindly discarding every immediate body loses later readonly source grammar, while preserving every body without inspecting nested commands misses rename, delete, rebind and expression substitutions. Callback and variable-observer effects cannot be inferred closed from literal command spelling.

## Question

How can the shared conditional source-transition tape inspect genuine original immediate scripts and operands before retaining later source-name advice, while keeping callback uncertainty and actual runtime selection independent?

## Conclusion

The existing authored source graph and typed transition receipts are reused. Complete original Body/case geometry, whole image, full config, actual ContextRegistry and same retained vector are required. The shared native script arena and checked Native expression-to-script bridge inspect genuine child commands, including lazy expression source possibilities. Possible known rename/delete/rebind changes shadow earlier source cells; speculative child publications never enter the enclosing graph. Unknown callbacks retain exact original child vectors plus UnknownEarlierMutation, and unresolved argv operands retain current pre-operand conditional grammar while withdrawing the later graph. The resulting SourceTransitions purpose always has operands_preserve_source_lookup=false and supplies no runtime, entered-frame, variable cell, native execution capability, Normal, semantic-rewrite or refactor authority. Typed non-Read VariableTraces, CommandTraces and ExecutionTraces access retains the exact registration/state-change producer as unresolved future observer state even when its synchronous reentrancy is Never. This does not claim that a registration succeeded or that a callback ran. A separate observer-state owner is required to close that uncertainty. Observer uncertainty consumes exact typed Trace transitions and observer-domain widenings in addition to residual world effects. Transition effect coverage can legitimately downgrade a represented trace write to a residual read; that downgrade does not establish closed future observer state or synchronous callback execution. The original complete registration producer remains an unresolved source obligation.

## Scope

Authored Rust assertions in C8.4, C8.5, C8.6, C9.0 and C9.1 source contexts. No new native interpreter observation or Rust execution receipt. Literal puts has unclosed channel/execution callback effects and is not claimed runtime-pure. Non-current interpreters, nonempty scoped bodies, incomplete/cooked geometry, unsupported checked expression contexts and traversal budgets withdraw the graph. Jim and BIG-IP are not measured by these selectors.
