# naming.source.original-direct-token-owner

Kind: `implementation-contract`

## Problem statement

Conditional source metadata consumers need the complete current original written carrier. A Direct source entry can retain that carrier without a separate Native compiler visitation receipt; using the visitation query as source ownership would lose this independent metadata purpose.

## Question

Which retained source facts authenticate the complete original written token carrier under a Direct entry, and what independent admissions do its seven actual source consumers still require?

## Conclusion

RetainedSourceModuleBindings::owns_original_tokens uses only the genuine retained written vector and config, retained original lookup snapshot, same invocation/current/positioned root source, retained image/channel, compatibility argv and complete immutable producer baseline. A missing or foreign source purpose refuses. Source ownership supplies no Native compiler receipt, actual handler, physical read/store, normalisation or source edit.

Complete original written vector/compatibility argv, retained image/channel/configuration, same invocation/current/positioned origin, lookup snapshot and immutable baseline authenticate source ownership only. Whole Module and supplied metadata/refusal guards remain independently required at each consumer. No reachability, compiler visitation, Native handler/frame/body/cache/read/store/Normal, value solver, rewrite or applied edit is donated. No matching executable inventory/assertion, external-provider or measured performance result is attached.
