# naming.navigation.retained-path-source-inventory

Kind: `implementation-contract`

## Problem statement

Path-variable and namespace-scoped file/package source advice can combine original source words with values from another source image, grammar or lookup scope. Authored path hints need exact retained input and whole original operand positions independently of current runtime values.

## Question

How do path-variable, namespace-scoped file and package source-advice consumers retain the same complete analysis, source image, availability, configuration and original whole-word positions?

## Conclusion

constant_path_assignments_from_analysis requires the actual retained input, whole Document source image and exact body lexer policy. OriginalRegistryWords and selected Registry source-navigation/assignment layouts retain effective whole-word ordinals under current availability; iterative source scopes preserve the authored naming purpose and independent barriers. Path folding uses the shared path algebra and selected braced-variable grammar. Variable scalar/closed-element geometry remains distinct from namespace naming, including empty scalar names and parenthesized namespace literals. Core typed source link projection uses this inventory and actual source navigation, refusing stale/missing input, known shadows and captured-only anchors. These are conditional source hints, not observed values, executed namespace/body, native cell/frame or an edit permission. SourcePathOperation selects Join, Dirname, Normalize or ScriptPath from the actual selected schema and effective argument ordinals. capture_source_path_expression retains a flat original-source plan; OriginalSourcePathExpression::evaluate uses an explicitly supplied document filename and selected variable resolver. PathConstantValue::Original retains this plan without reparsing its evaluated value as source. Selected list renamed as file supplies no path operation, while authentic bound values remain one value even with dollar, Unicode or semicolon bytes.

## Scope

Six marked source/API controls cover whole input/config and source scalar names, absolute namespace scopes, selected brace-close grammar, selected assignment/navigation layouts, shadow/stale refusal and namespace/variable name-domain separation. A direct Jim084 source simulation can advise its original local namespace link without exporting its path value; the public Native document-link entry stays empty without independent current-value proof. An unknown Jim079 naming recipe refuses. All seven external provider rows are not tested for this contract. This inventory does not prove a file/package load, existence, installed runtime binding, native body entry or successful command execution; other path producers retain their separate premises. Actual analyser full, chunked and restored command batches delegate to extend_path_constant_assignments_from_analysis_commands. A retained inventory key includes the complete source input, whole image, configuration, actual immutable Realm Arc identity and explicitly constructed source root. Batches in the same walk extend that inventory. A changed actual realm/input/root reselects the already covered byte-identical prefix once before extending; an altered prefix or missing/stale premises withdraws its facts. An explicit source-local root remains conditional source geometry, not an entered namespace. Three marked producer controls cover equal full/chunked/restored projections, changed-realm and prefix withdrawal, explicit root seeding and selected-setter replacement refusal. No elapsed-time, current-value, native binding or successful file/package execution is established. Typed source operations, complete effective argv and authentic original whole-word provenance govern path folding and Core link projection. Unknown, cooked, expanded or multiple-command inputs, missing/foreign/stale metadata and lost original source ownership decline. The selected Jim0.84 ScriptPath source recipe uses an explicit current document filename for advice; unknown Jim0.79 metadata cannot borrow it. Namespace names retain their own literal naming purpose, separate from scalar/closed-element variable geometry. Authoring/render/load parity preserves the same selected descriptor without granting runtime info script, successful filesystem access, current stored path values, entered namespace/body or Native link authority. SourceTarget and auto_path consumers capture genuine original whole words under the same complete analysis/input/config, source image and immutable Realm/inventory owner. The selected source-navigation schema and operand membership remain independent of reporting path or form. A child declaration retains its separate original source-load lineage. OriginalSourceAutoPathExpression applies the selected mutation after the whole argument value is complete: Assign splits it using the retained list grammar; Append keeps one whole element. Bare auto_path requires the retained root source namespace outside definition bodies, while unresolved local/global alias receivers decline. WorkspaceSource retains the sealed expression plan and SourceResolver folds it against the same inventory; installed source edges, namespace seeds, constant imports, run order and package ancestry consume this plan. Explicit literal-only compatibility APIs remain separate. These source/API controls establish no runtime filename/cwd, current stored path value, file/package execution, installed native receiver or entered namespace/body.
