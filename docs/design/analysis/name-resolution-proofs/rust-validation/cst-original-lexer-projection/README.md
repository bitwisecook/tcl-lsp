# Original CST lexer projection evidence

The independent driver compares the semantic and lexical CST APIs with the original configured lexer records for 126 dialect, input and source-channel combinations. The semantic API deliberately omits trivia and differs in 112 combinations; the lexical API matches all 126 original record vectors. Both executables are compiled from the exact three included CST owners and the recorded Lexer library.

[The original receipts](receipts.json) retain the exact compile and launch vectors, statuses, streams and image identities. [The retention map](retention.json) joins whole source, compiler and Lexer library inputs to lossless stored bytes. This diagnostic does not execute the full Compiler library assertions, the segmented command consumer, a native Tcl/Jim interpreter or BIG-IP.
