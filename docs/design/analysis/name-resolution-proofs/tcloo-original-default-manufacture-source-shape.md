# naming.tcloo.original-default-manufacture-source-shape

Kind: `implementation-contract`

## Problem statement

A source coverage walker must distinguish a default instance manufacturer from a command that invokes an arbitrary constructor or dispatch filter. A later instance proof or a class reporting label cannot establish the argument execution shape at the original manufacture command.

## Question

Can the authentic original command point issue default-manufacture source argument-shape advice for one exact current ordinary class whose lifecycle and dispatch handlers are independently absent?

## Conclusion

The issuer retains the full static original vector and exact current class implementation, joins the same Registry and selected ordinary factory recipe, and requires closed absent lifecycle entries, no ancestors, filters, class-object overrides or dispatcher. It selects the exported manufacturer and its argument count through the retained grammar. The receipt identifies the independently selected class declaration and supplies source shape only; allocation and completion remain separate.

## Scope

Read-only Rust source advice at reached C8.6, C9.0 and C9.1 original command points. Native entries, configurable support, expanded or computed arguments, source ancestors, nondefault lifecycle bodies, unavailable instance inventory, class-object methods, observer effects, unknown tables, foreign Registry selection and synthetic vectors decline. No Normal completion, actual object allocation, native preparation, executable body or edit coverage is issued.
