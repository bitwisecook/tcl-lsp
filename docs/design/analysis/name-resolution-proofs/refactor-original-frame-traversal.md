# naming.refactor.original-frame-traversal

Kind: `implementation-contract`

## Problem statement

Reanalysing a body slice at offset zero can borrow another namespace, parser configuration or command binding. A string search for brackets also confuses literal data with executed substitutions. Region traversal therefore needs original absolute geometry and separately selected Registry body roles; unknown regions cannot become a closed traversal.

## Question

Does refactoring traverse authentic original same-frame and shifted-frame regions in the complete document?

## Conclusion

FrameWalk retains the actual profile, Registry, Realm and full configuration with whole-image correspondence. Native traversal consumes original executable arenas and independently selected conditional structured body roles, keeping absolute extents and explicit incomplete/depth states. Braced data remains data. It grants no body execution, frame relocation, Normal successor or variable store.

## Scope

Shared Core refactor region inventory for original commands, expressions, clause/lambda lists and command substitutions. Unsupported geometry and unowned structures withdraw completeness; the legacy walker is only lexical authoring advice.
