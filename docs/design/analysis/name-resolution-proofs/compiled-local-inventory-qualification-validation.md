# naming.compiled-local-inventory.qualification-validation

Kind: `native-observation`

## Problem statement

Namespace separators before or after raw zero can be reached by formal validation even when the error presenter shows only a prefix. A display string is not the stored formal key or a proof that the procedure was installed.

## Question

Do qualification-before/after-zero original formals install and reach local inventory in each release?

## Conclusion

C8.4/8.5 accept qualification after raw zero, enumerate k with one formal, and reject the two-argument call with usage p k; they reject qualification before zero at definition. C8.6–9.1 reject both qualified-name cases at definition, and the following attempted invocation reports invalid command p. Jim accepts both counted qualified forms and enumerates their complete original members for one/two formals. C error presentation can truncate raw zero independently from validation; exact error bytes are retained.
