# naming.tcloo.original-class-relation-candidates

Kind: `implementation-contract`

## Problem statement

A hierarchy barrier can join a written superclass operand to unrelated classes by reporting-name tails, or treat an unmatched or unavailable class as an empty local edge set. The original enclosing definer, selected member, target allocation and inherited dependencies then disappear behind QName labels.

## Question

How does the method propagation barrier form only retained class-allocation MAY edges under the actual complete selected source, and widen when source, ancestry or local projections are unavailable?

## Conclusion

Lowering retains the complete original enclosing definer and member vectors with the selected target/body ordinals. The shared source query rejoins the actual retained Module, positioned holder, complete original source purpose, Registry definition grammar, member class-reference role and body/source geometry. An original factory publication instruction or the canonical original class configuration operand supplies the declaring Class allocation. The existing completed source ClassDefinitionReceipt and dependency-currentness worker supply the inherited allocation candidates. Exact allocation reporting projections join the local MAY component graph; missing source/metadata/vectors, unavailable or non-Class targets, unknown dependencies and unmapped external ancestry widen the barrier before the empty bad-class shortcut. Labels grant no class, method dispatch or entered receiver. Protected braced operand punctuation remains original source data. Five fixed software controls are source definitions only and carry no assertion/provider outcome.

## Scope

Finite IR ClassRelation carrier, the two enclosing Lowerer extraction ports and sole relation-member producer, the shared SourceCommandBindings class relation candidate query and the sole method_barrier hierarchy consumer. Existing class parsing, current dependency selection, dispatcher/receiver entry and method dispatch facts remain independent. This is MAY effect scoping, not ancestry validity, lookup absence, exact dispatch, runtime class inventory, local-cell propagation execution or external provider equivalence.
