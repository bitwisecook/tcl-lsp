# naming.source.incomplete-body-header-metadata

Kind: `implementation-contract`

## Problem statement

An open quoted procedure body has no complete body word or installed declaration. Requiring those owners loses signature grammar while the user types; manufacturing a closing quote would substitute another source.

## Question

Which readonly Registry grammar can an original incomplete procedure-body prefix supply?

## Conclusion

The actual parse cut identifies an open quote after independently complete header words. A retained original table snapshot selects the procedure descriptor and its conditional publication namespace. The unchanged first literal child command can project possible Registry metadata without creating a complete body, installation, formal activation, executable facts or Normal completion. The authentic missing-quote cut retains one final source body slot for conditional descriptor cardinality, without creating its runtime value or a complete NativeWord. The same actual cut and independently selected procedure header supply conditional cursor-region geometry under full original image, configuration and Registry currency, even when the rejected outer command has no executable head binding. Child lookup is still issued separately.

## Scope

Only a first malformed command with a final missing-quote cut and an original, unconverted Text-only body prefix is covered. Header source is bounded at 64 KiB and sixteen complete words. Earlier body commands, substitutions, escapes, captured prefixes, unknown tables, foreign words and missing native naming purpose decline. Native compilation and body-entry obligations remain unchanged. No native or Rust execution result is claimed. Cursor-region geometry can include the unchanged body prefix without claiming a complete body or a successor command table; only the existing first-child advice selects child Registry metadata. The cursor region is restricted to an original root source extent equal to the complete caller image at base zero, so its child lexer depth cannot be borrowed from another chunk.
