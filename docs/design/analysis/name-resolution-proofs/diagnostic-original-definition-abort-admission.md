## Question

## Conclusion

Class W315 and per-object W315 use this same admission owner. emit_w315_definition_cannot_run drains class abort candidates before refusing Native, hosted, missing-input or cross-file extension advice; authored source retraction tombstones remain. Only actual Logical compatibility applies its bounded source-model abort forms and corresponding reporting-table settlement. Reporting dialect/name/flag mutations cannot donate Logical input or Native worker/table closure. A source declaration or member order supplies no actual own-method absence, selected worker, closed table, guaranteed Native abort, object/class allocation, entered frame or edit authority.

## Scope

A Server integration control keeps the Native class outline while withholding W315. Existing source retraction records remain separate from executed Native method-table facts.
