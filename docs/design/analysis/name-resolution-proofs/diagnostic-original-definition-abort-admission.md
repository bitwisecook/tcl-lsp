# naming.diagnostics.original-definition-abort-admission

Kind: `implementation-contract`

## Problem statement

Class declaration and member-abort report rows can describe authored source without establishing the selected Native definition worker or a closed current own-method table. Copied labels and advice flags cannot turn those reports into a guaranteed Native definition failure.

## Question

When may class definition-abort reporting rows generate W315, and why do original declaration, name and member order fail to establish an actual selected Native definition worker or closed current own-method table?

## Conclusion

AnalysisResult::allows_retained_logical_declaration_advice requires positively retained actual Logical input together with the existing lexical advice mode and source/vendor exclusions. Class W315 and per-object W315 use this same admission owner. emit_w315_definition_cannot_run drains class abort candidates before refusing Native, hosted, missing-input or cross-file extension advice; authored source retraction tombstones remain. Only actual Logical compatibility applies its bounded source-model abort forms and corresponding reporting-table settlement. Reporting dialect/name/flag mutations cannot donate Logical input or Native worker/table closure. A source declaration or member order supplies no actual own-method absence, selected worker, closed table, guaranteed Native abort, object/class allocation, entered frame or edit authority.

Ten linked source-order controls specify conditional Logical retraction advice across instance/class sides, local declarations and external stubs. Dynamic names and visibility/filter words do not establish a definite abort; rejected rename creates no move record. Reports retain one whole original offending word and do not duplicate through later unrelated definition clauses.

## Scope

Three fixed Compiler controls cover Native/hosted refusal with positively injected abort rows and copied flags, absent retained input, and genuine Logical admission despite reporting mutations followed by lexical-mode withdrawal. A Server integration control keeps the Native class outline while withholding W315. Existing source retraction records remain separate from executed Native method-table facts.

The authored compatibility fixture carries its actual Logical source input and independently supplied declaration metadata. These controls do not measure original Tcl/Jim definition-worker completion, current own-method absence, allocation, entered body/frame, successful retraction, safe edit or assertion outcome. External stub tombstones remain source data, and existing Native/hosted admission negatives and all provider answers are unchanged.
