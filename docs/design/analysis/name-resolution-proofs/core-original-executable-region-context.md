# naming.core.original-executable-region-context

Kind: `implementation-contract`

## Problem statement

A naming consumer can rebuild source body grammar from a report head or a profile-only context, losing the actual whole source/configuration/Registry/realm and alias or shadow ancestry.

## Question

How can naming consumers traverse potential original source regions under the same full analysis input without deriving grammar from a reporting head or implying runtime body entry?

## Conclusion

visit_analysis_executable_commands and innermost_analysis_executable_region_at consume the actual retained AnalysisResult. Whole image/channel, full lexer configuration, actual Registry semantic generation, resolved input and retained realm must agree. Shared source_registry_words, source_script_bodies_for and genuine lambda/member source geometry retain conditional schema ancestry and effective-to-written coordinates. The executable walker explicitly asks for PotentialEvaluation, excluding ReferenceOnly syntax. An authentic incomplete-body region remains independently guarded. Method/receiver temporal identity is a separate receipt; source region geometry supplies no body entry, actual callable, frame, effects, Normal or edit permission. Native/hosted rename coverage and nested reference dispatch-region collection use the same actual Analysis facade; conditional body geometry cannot replace temporal method or callable identity. Core executable traversal consumes the sealed genuine member/source-expression issuers and complete NativeWord executable parts. Complete parent vocabulary and body geometry remain owned; only authored wrapper blocks propagate member vocabulary. Declared Body roles require independently selected timing before PotentialEvaluation. Unknown member selectors/parameters, unavailable release words, cooked body geometry and declared Syntax-only bodies refuse executable traversal; complete compound words retain only their genuine live substitution spans. This potential-source inventory supplies no reached body, entered frame or Normal completion. ExecutableWalker::original_source_regions uses the shared OriginalSourceScriptBody::definition_parent_for source-vocabulary rule and the retained complete member-region issuer. Only a selected authored opening or actual Plain/current/SameInvocation source body contained by the same full parent image/configuration/context inherits vocabulary. Structural, deferred, ReferenceOnly, foreign and uncontained bodies decline. Immediate control source can retain the genuine class parent; ordinary method/procedure/lambda bodies cannot donate its member Body layouts. Source parent selection remains independent of PotentialEvaluation, entered frames, Native handlers, successful completion and compaction/edit authority.

Four additional marked Core definitions retain absolute original case/body spans and authentic alias geometry, reject malformed/dynamic or non-mappable quoted bodies, and keep ReferenceOnly syntax outside Potential executable traversal.

## Scope

Core source region traversal and cursor selection. Native and hosted branches require actual retained analysis; the profile-only compatibility walker is independently constrained to positive Logical/Tk compatibility. Known source shadows and stale source/config/Registry refuse nominal grammar. Alias case-list and lambda source regions keep original containers and conditional applicability.

Potential source traversal is conditional source geometry, not entered execution or handler lookup. These definitions establish no Native body/frame/Normal, read exclusion, current command identity, edit permission or new assertion result.
