# naming.tcloo.original-property-accessor-source-advice

Kind: `implementation-contract`

## Problem statement

A configurable property declaration names a counted value, while its generated configure option is formatted from the C string extent. A completion consumer can otherwise merge raw-zero and encoded-zero names, mistake a value argument for a property option, or infer a generated accessor from a reporting metaclass label. Source advice must retain the selected grammar protocol, the original producer and the distinct naming purpose.

## Question

Does source property advice retain the selected accessor argument layout and project its option name independently from the original counted declaration name?

## Conclusion

The selected source grammar retains an immutable accessor protocol: no arguments list readable properties, one argument names a readable property, and even name/value pairs name writable properties at even ordinals. The C9 option projection adds a dash to the declaration C string extent while retaining the full original counted name separately. Neither facet proves an installed accessor, a reached property lookup, native object or cache identity, successful completion, or editable produced-value geometry. Readonly completion uses OriginalSourcePropertyMetadata::matches_original_declaration_source: complete Document image, actual input/configuration, authentic SourceClass receipt, canonical provider pointer, private original property-ledger membership and original naming key must agree. Foreign same-source provider or stale image refuses. Strict entered-definition-frame/edit matching remains separate; readonly source correspondence needs no entered body.

## Scope

Rust source-advice selection for Tcl 9.0 and 9.1 configurable property declarations and exact counted accessor selectors. Controls distinguish raw zero, native encoded zero and opaque surrogate bytes, reject other accessor spellings and invalid argument parity, and keep non-property grammars and C8.4–8.6/Jim purposes unavailable. These are implementation assertions with Document producer controls; no C Tcl, Jim or BIG-IP execution result is claimed.
