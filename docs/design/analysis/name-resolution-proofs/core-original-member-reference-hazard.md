## Problem statement

## Question

How does member-reference hazard advice retain genuine original parent vocabulary, actual availability and whole source operands without granting installed members or an unsafe edit?

## Conclusion

DefinitionBodyGrammar::source_member_ref_indices_in consumes exact structured argv width under the selected parent vocabulary and actual query; control selectors and slot words require static byte correspondence, while dynamic values retain their independent state. OriginalSourceDefinitionMemberRegion retains the full original command plan and complete genuine parent source/context. Its references entry requires every supplied word to belong to one complete command in that plan, delegates selected member-reference roles, and seals each readonly OriginalSourceDefinitionMemberReference with its original operand, byte value, kind and selected naming protocol. Wrapper offsets retain the actual child operand. Dynamic values contribute no static reference candidate; expansions, truncated or foreign argv, unavailable parent vocabulary and retired context refuse. Resident space/NUL units are source value/name-purpose controls only. This source inventory supplies no actual installed method/class/receiver, entered frame or successful rename/edit authority; Core hazard integration keeps its own independent carrier and currency requirements. Core member_metadata::spans consumes this inventory only after full original image/configuration, retained input/profile/realm and actual ContextRegistry checks. A genuine class factory or selected class-configuration operand joins the canonical original class; explicit Logical class advice uses its independent positive input and unique source correspondence. Genuine wrapper and immediate caller bodies retain their selected parent vocabulary. Custom schemas and source class moves/captured operands remain current, while known deletion/replacement, missing input, foreign image and unowned class metadata return no hazard spans. Matching a presentation method name filters this already authenticated source inventory and cannot select an actual method table, entered worker or edit permission.
