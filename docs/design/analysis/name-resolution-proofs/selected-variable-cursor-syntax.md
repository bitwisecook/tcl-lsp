# naming.core.selected-variable-cursor-syntax

Kind: `implementation-contract`

## Problem statement

A cursor label or guarded source rename can select the wrong name when it scans delimiter characters independently of the actual analysis grammar. Whole scalar parentheses, literal dollars, nested array-index references and conditional source-body applicability require the same original component owner.

## Question

How do editor variable cursor labels retain actual current analysis, selected variable grammar and original component geometry while ordinary complete rename remains refused for source-only Logical variables, and what separately admits a conditional single-document source alpha proposal with versioned confirmation and all three client capabilities, without granting Native, runtime-observer or workspace-completeness authority?

## Conclusion

ExecutablePartArena::variable_part_at selects the smallest genuine original variable component, including nested index children. Core original_variable_reference_at joins that component through the complete current SourceStructure, actual source/config/input/context and independent comment/data applicability. Shared selected whole-reference roots and the closed-element name partition preserve scalar unmatched/tail parentheses and literal dollar units. Definition, hover, type-definition and declaration consume the same source geometry; their binding/type/navigation authorities remain independent. Hover inference retains the actual analysis context, and Logical declaration/lambda scans retain the actual realm/config and authentic lambda body word. Ordinary complete variable rename remains refused when source-only Logical analysis lacks independent complete edit authority. A separate conditional single-document source alpha proposal requires exact original and generated source images, authentic retained analysis input/context and typed symbol naming policy, one-to-one written occurrences and strict source/scanner correspondence; stale source or missing geometry refuses. Its server publication requires a versioned document edit with a confirmation-required change annotation and all three client capabilities: workspace documentChanges, workspace changeAnnotationSupport and rename honorsChangeAnnotations. The standalone hover utility explicitly chooses its own source lexer configuration and supplies only a syntax label. None of these source labels or conditional proposals proves Native cells, read completion, frame entry, AST/SSA runtime identity, current storage, runtime-observer safety, workspace completeness or Native edit authority. Independent native expression public rows remain separately scoped.

## Scope

Seven marked source/API controls cover original nested components, literal dollars, selected FirstClose/Tcl9Nesting braced-variable styles and Unicode/UTF16 offsets, complete source roots/spans, custom ReferenceOnly/prefix roles, malformed/data and stale/missing/config refusal, and the distinction between ordinary complete-route refusal and separate conditional single-document source alpha planning. The five-case rename coverage obligation retains `scalar(open`, `scalar(open)tail`, `cash$name`, `$n` and `café🙂`, exactly two core declaration/reference edits, the exact generated source `set {new} 1\nputs ${new}\n` and stale-source refusal under authentic source/config/input/context and typed naming policy. Versioned confirmation with all three client capabilities is a separate publication requirement. The related pure Syntax closed-element control is bound to the selected-reference-root question. All seven providers are not tested for cursor/edit API assertions; standalone selected syntax, conditional source proposals and analysed navigation/edit authority remain distinct. No executed-result, Native, runtime-observer or workspace-completeness claim is attached.
