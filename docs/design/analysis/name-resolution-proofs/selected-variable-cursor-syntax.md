# naming.core.selected-variable-cursor-syntax

Kind: `implementation-contract`

## Problem statement

A cursor label or guarded source rename can select the wrong name when it scans delimiter characters independently of the actual analysis grammar. Whole scalar parentheses, literal dollars, nested array-index references and conditional source-body applicability require the same original component owner.

## Question

How do editor variable cursor labels and positively admitted Logical rename projections retain the actual complete analysis, selected variable grammar and original component geometry without granting a Native read, binding or edit?

## Conclusion

ExecutablePartArena::variable_part_at selects the smallest genuine original variable component, including nested index children. Core original_variable_reference_at joins that component through the complete current SourceStructure, actual source/config/input/context and independent comment/data applicability. Shared selected whole-reference roots and the closed-element name partition preserve scalar unmatched/tail parentheses and literal dollar units. Definition, hover, type-definition and declaration consume the same source geometry; their binding/type/navigation authorities remain independent. Hover inference retains the actual analysis context, and Logical declaration/lambda scans retain the actual realm/config and authentic lambda body word. Guarded Logical rename uses the original whole component and strict scanner correspondence, refusing source drift or missing geometry before edits. The standalone hover utility explicitly chooses its own source lexer configuration and supplies only a syntax label. None of these source labels or chosen rename controls proves Native cells, read completion, frame entry, AST/SSA runtime identity, current storage or Native edit authority. Independent native expression public rows remain separately scoped.

## Scope

Seven marked source/API controls cover original nested components, literal dollars, C/Jim/iRules selected grammar and Unicode/UTF16 offsets, complete source roots/spans, custom ReferenceOnly/prefix roles, malformed/data and stale/missing/config refusal, and authentic positively retained Logical rename projections. The related pure Syntax closed-element control is bound to the selected-reference-root question. All seven providers are not tested for cursor/edit API assertions; standalone selected syntax and analysed navigation/edit authority remain distinct.
