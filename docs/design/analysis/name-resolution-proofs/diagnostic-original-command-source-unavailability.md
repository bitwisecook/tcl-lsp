# naming.diagnostic.original-command-source-unavailability

Kind: `implementation-contract`

## Problem statement

An excluded Registry row is advisory metadata under a particular full context. A String spelling, reporting dialect or raw written argv cannot establish that the genuine source invocation owns that exclusion, and unavailable metadata cannot establish a missing runtime command.

## Question

How do disabled-command diagnostics retain exact original source identity and full-context exclusion metadata without acquiring an admitted schema, handler or runtime command absence?

## Conclusion

ResolvedContext and ContextRegistry select negative availability metadata from the actual immutable Registry generation, related provider rows and invocation realm. OriginalSourceCommandAvailability retains the complete original vector and positively selected Native, Logical or hosted source domain under its full image/input/configuration/context and independent lookup or hosted ancestry. Known declarations, custom cells and source barriers remain authoritative. W002 and IRULE2004 retain a typed source-current subject; Core transport preserves the command, exclusion classification and source domain independently of message text. No admitted descriptor, handler, runtime absence or successful completion follows.

## Scope

Excluded Registry metadata comes from the exact resolved context and actual store/provider rows. Genuine complete original vectors select independent Native/Logical/Hosted origins, retaining full input/source/config/context/lookup or vendor barriers. Known declarations, custom cells, dynamic heads and foreign inputs withdraw nominal metadata. W002/IRULE2004 own a typed subject and source-current flush; Core transport preserves purpose/domain without reparsing messages or recreating authority. No admitted descriptor, selected handler, runtime absence, Native execution or successful completion follows. Six linked Rust controls cover actual related and overlay provider rows, genuine Native source with cleared reporting maps and source/config/context/shadow negatives, hosted loader policy distinct from interpreter availability, positively sealed Logical source versus unknown domain, and typed Core transport after changing reporting text. These controls supply no native execution or current-source Rust assertion outcome.
