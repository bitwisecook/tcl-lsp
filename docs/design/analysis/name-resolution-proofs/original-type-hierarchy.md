# naming.consumer.original-type-hierarchy

Kind: `implementation-contract`

## Problem statement

Class displays can collide, namespaces can contain an earlier non-class publication, and equal source copies can belong to distinct documents. A hierarchy item needs the actual selected source declaration and each relation operand's retained lookup coordinates.

## Question

Do hierarchy queries preserve exact original class declarations and document owners without borrowing reporting names?

## Conclusion

Prepare retains a current class declaration identity. Direct superclasses and mixins use the shared original relation kernel with occupied non-class headers; ambiguous providers decline. Workspace joins preserve URI ownership and recheck complete source and scanner configuration. Wire locators refer to bounded retained identities and supply no declaration authority by themselves. The result is source declaration advice, independently of runtime class installation and MRO.
