Implementation contract: `naming.core.original-definition-grammar-cursor`.

`SourceStructure` owns the source-body walk for the actual retained analysis.
Its definition-cursor purpose preserves the same original Document image,
complete resolved input, full lexer configuration and actual Registry/context.
Each nested region retains its real `OriginalSourceScriptBody` and
`OriginalSourceDefinitionMemberRegion`, including the original full command
vectors and body containers. Ordinary member bodies carry an explicit ordinary
script context. No report scope or `HeadWords::plain` text projection selects a
current vocabulary.

Closed declaration-document blocks use the genuine source head and selected
source schema. The Registry's authored parent/member relation must agree with
that schema's child grammar before its actual body is queued. This changes no
ordinary readonly, syntax-compaction, checked-syntax or mutation-coverage purpose.
Selected grammar reborrow rechecks the original image/input/configuration and
actual body context/schema. Renamed presentation labels supply no selection.

The result distinguishes selected nested vocabulary, explicit standalone root
authoring, ordinary script context and unavailable traversal. Unrepresented or
cooked operand interiors, malformed regions, ambiguous ownership, missing parent
correspondence and the 32-level cursor budget never select the prior grammar.
A standalone root has its genuine configured `document_grammar`, not a forged
body. Its root authoring projection may retain unavailable-child debt and still
suggest that explicit root vocabulary; it supplies no selected-child claim.
Candidate edits reject that debt. The compatibility standalone vocabulary API
remains a separate caller-authored utility and also declines at its depth cap.

projection, retaining the original typed notice, unchanged whole source,
configuration, Registry and edit guards. Existing flag-option candidate selection is
unchanged and receives no new selected-parent or command authority from this
property-vocabulary adapter. The selected source grammar grants no
handler dispatch, entered definition/member frame, Native naming, absence,
closed lookup, effects, runtime execution or Normal completion.

Fixed controls exercise original nested member/wrapper/control bodies and
ordinary method scripts; authored parent/child vocabularies; shadowed, dynamic
and equal-spelled data refusals; standalone BOM policy/root debt; complete input,
configuration and image reborrow; malformed and deep cutoff refusal; Unicode

fixtures and assertions remain unchanged. Source review is independent of later
