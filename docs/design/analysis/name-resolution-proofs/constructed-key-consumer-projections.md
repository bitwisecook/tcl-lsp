# naming.analysis.constructed-key-consumer-projections

Kind: `implementation-contract`

## Problem statement

Analytical command/class/procedure inventories and diagnostic groups use different name presentations. Local delimiter splits can collapse a constructed lone-colon segment or mistake literal reporting geometry for an original namespace/procedure owner.

## Question

Which shared projection governs literal diagnostic QName grouping versus constructed class/procedure/inventory holders and tails, and what independent producer/source/metadata guards remain necessary before actual lookup, factory or creation reasoning?

## Conclusion

Literal W214 grouping delegates reported_qname_namespace with LiteralPrefix and keeps its existing String/default semantics. Constructed graph and inventory consumers delegate key_holder_and_tail or key_tail, preserving lone-colon segments, root/bare holders and qualified nonempty recovery selection. The query does not recover an arbitrary native component path. Existing original source class lookup, positioned procedure/invocation, original module/source/availability correspondence, hierarchy and manufacturer/layout requirements remain independent; displayed labels cannot replace absent receipts. Four fixed software control definitions exercise the actual reporting, graph, recovery and placeholder helper surfaces. No assertion outcome, external provider execution or general source/factory/type-soundness closure is attached.

## Scope

Current analytical projections for eight local production splitter sites in five Compiler leaves. One is literal reporting; seven are constructed graph/procedure/inventory projections. Four fixed source-defined controls are unexecuted. Colon/Unicode/NUL reporting inputs are metadata examples, not native namespace semantics or addressability observations. Existing original command/namespace/class/procedure receipts and logical compatibility admission are unchanged. C Tcl/Jim/BIG-IP processes are not applicable and not tested; no Native getter, callback chronology, dispatch, class/factory or creation effect is inferred.
