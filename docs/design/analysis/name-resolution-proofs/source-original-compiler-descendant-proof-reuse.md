# naming.source.original-compiler-descendant-proof-reuse

Kind: `implementation-contract`

## Problem statement

Repeated original compiler descendant name-effect inquiries can reparse the same retained regions. A shared result is invalid if it crosses source origin, lookup world, compiler context or external native currency.

## Question

How can repeated original compile-time descendant name-effect inquiries share a completed proof without mixing source origin, immutable lookup world or compiler context, or granting execution/frame/admission?

## Conclusion

SourceCompilerNameEffectsCache belongs to one immutable source lookup snapshot. preserves_visits reuses completed true/false descendant results only when the supplied state is that exact snapshot table and no physical Native entry requires external currency. The key retains full SourceImage/channel/span/configuration, SourceOriginId, original namespace, Registry semantic key, invocation realm and NativeCompilationContext; immutable snapshot baseline supplies its selected dialect/profile, lookup/entry and observer world. Each descendant region retains original preparation visits and current callback/effect barriers. Detached snapshot Clone and join reset the derived memo; its population is excluded from semantic Eq/Hash. Missing/changed literal, actual state, compiler context, source or unknown lookup cannot borrow an older proof. Iterative descendant traversal keeps refusal distinct from success and never issues reached command, entered frame, inline/compiler admission, runtime effect or Normal completion.

## Scope

Current authored compiler name-effect proof reuse. Three deterministic fixed source controls count parsed regions per immutable lookup point, preserve exact refusals/source/compiler context and reject changed literal or actual lookup world. These counts are implementation assertions, not elapsed-time or native provider observations. All seven providers are not tested; independently executed deep production controls retain separate validation receipts.
