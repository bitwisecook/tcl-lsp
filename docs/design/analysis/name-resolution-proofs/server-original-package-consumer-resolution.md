## Problem statement

W123 suppression must be based on the exact original requirement context rather than a package label or a blanket package-command inventory.

## Question

Actual source availability remains independent of package preference and successful loader or factory execution.

Configured package refinement keeps version preference separate from each provider's selected source dialect and owner. Unknown or unavailable providers leave dependency closure incomplete, so W120/W123 abstain without fabricated publications.

Package recovery reads requirements from the current actual analysis, preserving exact versions and preference separately from each provider source owner. Its conditional cache retains caller/provider input and workspace/resolver currency. Missing, unavailable, dynamic or unenumerable providers keep dependency closure incomplete; registry-provided requirements remain separate from missing source-file enumeration.
