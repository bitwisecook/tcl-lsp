# naming.variable.separate-root-index-list-conversion-and-failure-stages

Kind: `native-observation`

## Problem statement

An original root object and a separate index object can begin as pure list objects or a fresh/cached combined spelling. Lookup may materialise either string, install a parsed cache, reject a scalar root or parent namespace, or accept a true array; one generic combined spelling cannot represent those stages.

## Question

Separate root/index resident-list conversion, cached combined root and write flags What exact stages and results occur in the retained native probe?

## Conclusion

The fifty original C records distinguish five root shapes in quiet/error-reporting modes: missing namespace, scalar root, array root, fresh combined root and already cached combined root. Their exact headers/conversions and selected/null/result outcomes apply only to these original objects and API path; normal success, compiler locals and arbitrary object hooks remain independent.

## Scope

C84-91 ten cases/provider, separate Tcl_ObjSetVar2 input, original list object/root-cache shape, pre/post header reporting with exact result sentinel; no Jim/BIG-IP.
