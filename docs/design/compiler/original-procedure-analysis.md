# Original procedure analysis owners

Procedure names are source data and reporting labels. `ProcedureId` identifies a body issued by one actual `Module`; consumers retain that module, its current source image, complete analysis input, configuration and declaration receipts.

`Module::original_source_procedure_bodies` owns the source inventory. It includes primary procedure bodies and independently validated original declaration bodies. The Native allocation-backed declaration inventory, Native-name source cards, Logical declaration cards and Hosted declaration cards keep separate purposes. Anonymous and installed-only bodies do not become original source declarations. A source declaration supplies no installed command, executing body, Native formal ABI or physical frame.

| Query | Current owner requirements |
| --- | --- |
| `CompilationUnit::function_for_body` | Same Module issuer, one actual body store and a matching FunctionUnit body stamp. `None` selects the actual root unit. |
| `CompilationUnit::original_procedure_for_body` | Membership in the shared current original source inventory. |
| `CompilationUnit::original_procedure_cfg_for_body` | Original source inventory plus the independently prepared CFG retained before lattice analysis. |
| `LatticeRequest::original_source_procedure` | Current complete source, issued body, original body coordinates, formal vector and offset-zero original IR agree. |
| `CompilationUnit::accepts_original_procedure_lattice` | Current retained header, source/input/store and prepared CFG agree with the already-computed candidate after rebasing. A refusal withdraws its downstream baseline key. |

`OriginalNativeProcedureBody` retains original Native-name procedure syntax under one of two separate recipes: an `OriginalProcedureReadFlowEntry`, or a frame-free source declaration from the authentic original transition tape. The source recipe retains the original name operand, selected ParamList topology, body/schema, declaration byte slot and dialect namespace geometry; it supplies no physical namespace token or frame. The complete input, source/configuration/Registry, name operand, formal topology, original body and Lowerer-issued Script must agree with the actual current Module entry and body row. The separate Native source-card inventory supplies readonly `OriginalDeclaration` units without a successful implementation allocation or publication; those units are excluded from executable roots. Missing Native source ownership cannot borrow Logical or Hosted cards.

A frame-free Native source card can retain `OriginalNativeSourceBodyChildren` from its exact declaration source-origin Arc, complete input and immutable transition tape. Each child stamp matches the complete original vector; source words require the original body receipt and any present reached target must agree with the selected advice. `original_native_source_structured_invocation` rejects expansion and retains a distinct `NativeSourceSchema` requirement for readonly analysis hooks. Its MAY dependency query selects a terminal source reader when this child receipt is present. The requested original name bytes, complete vector and separate deferred-body purpose receipt must agree before the current Module/card/body and issued IDs can supply an open whole-inventory dependency set. Missing or poisoned purpose, known source barriers and incompatible reached metadata or targets refuse without entering the independent implementation lookup. These children supply no Native compiler admission, Normal effect, physical frame or selected call. Branch joins retain only the identical complete receipt.

Original declaration lattices retain their actual body ID and formals under the declaration's conditional source context. Their physical frame remains unknown. The source context independently retained at each CFG site owns any more precise source facts. Taint summaries, non-taint checks and optimisation slices join this same inventory by actual body ID; methods retain their separate instance-state overlay.

`FunctionUnit::original_hosted_procedure_body` holds the exact original Hosted card from the current Module after the card validates the source, declaration, body, input and Registry. Consumers compare the held Arc with the Module card and revalidate its current inputs. Event receipts stay separate; a hosted source procedure is not an executing iRules event or a Native procedure allocation.

`original_procedure_may_dependencies_for_word_for_module` keeps body-summary dependencies separate from a selected call. Its Native source branch matches the original static lookup against actual byte declaration slots, policies, current source cards and issued body IDs. Handler and alias alternatives remain open. Taint dependency readers retain every known body when alternatives or the original command head are unknown; this query supplies no return value, argument binder or executable call edge.

`original_logical_procedure_may_dependencies_for_module` retains a separate conditional body-summary purpose. The actual original caller vector, BodyWalk scope and current Module inputs join positioned declaration cards to issued Named or Logical declaration body IDs. `matches_original_procedure_summary` compares the retained body source geometry, formals, direct statement spans, body kind, publication and declaration site by issued ID; qualified reporting labels do not select the owner. A named-only descriptor can exclude procedure dependencies only when its source transitions retain no alias or mutation uncertainty. Global and CFG readers consume these body IDs and opacity without borrowing argument, return, selected-call or Native facts.

A Native Source-schema correspondence certificate validates the actual current input and source entry, original card/body/issued ID and immutable child tape. It retains original command/arguments/origins/roles/dialect, namespace/path/applicability and actual command-observer/source-step state before clearing private comparison carriers. Ordered body-local uncertain operations retain exact original bytes, configuration
and injective relative extents; recorded uncertainty is not a quiet-world proof.
Unsupported effects, lineage, foreign/out-of-body operations or expansion refuse comparison. Positioned Native ReadFlow retains its separate collector. Full capsule comparison additionally validates the current FunctionUnit and unique original name policy/slot while retaining function, summary, module and semantic facts. `BodyLatticeInputs::certified_native_source_body_id` returns only that retained issued body coordinate; reuse restores the current body ID and source/variable proofs. Neither the private comparison nor this coordinate selects an executable body.

Raw memo inputs retain actual identities and complete dependencies. Private correspondence certificates can permit reuse only for their supported source and dependency cases. Cached facts rebind to the current original owner, and the current prepared CFG must still agree. Neither equality nor an unchanged display name supplies callable, variable-cell, compiler, object, frame or execution authority.

Literal empty and sigil-bearing values remain name data. This possible-name
