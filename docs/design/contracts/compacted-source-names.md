# Contract: compacted source-name construction

`AuthoredCompactNameSequence` in Syntax's existing naming owner proposes new
lowercase ASCII spellings in length-first order: a through z, then aa, ab and
so on. It retains the entire supplied `LexerConfig`. Each candidate must pass
the existing `lexical_ascii_source_word` and `scalar_source_reference` owners;
the literal name word must equal the proposed bare bytes. The typed result is
new authoring data, with its original grammar available independently. It is
not a retained source occurrence or an existing command/variable identity.

`next_avoiding_observed` advances the same sequence for every rejected proposal.
The supplied predicate reports exact observed collisions only. Its false answer
is not an absence, completeness, uniqueness, availability, interpreter state or
creation licence. A finite attempt budget counts every proposal, including
collisions; an absent limit preserves an unbounded authoring search. Grammar
refusal is terminal; no alternate profile or Native protocol is synthesized.

The Core minifier supplies its actual complete input's lexer configuration at
all six uses: procedure compaction, local-variable compaction, isolated Logical
formal compaction, and command, argument and string aliases. The existing
1000-attempt limit remains at each local/formal request. Procedure and alias
searches retain their unbounded budget. Existing candidate ordering, known-name
sets, cost decisions and claiming only after selection are unchanged.

The sequence supplies no transformation permission. The minifier's existing
complete source census, scope barriers, original reference/formal geometry,
Native alpha proof and isolated Logical formal binding remain independent.
Aggressive alias construction remains explicitly observable new source;
unknown interpreter variables and incomplete source inventories remain debts.
No report label is converted back to a binding, and no Source receipt becomes
Native or Normal authority.

The owner-resolution public manifest registers the actual Syntax API and the
existing Core adopter. Fixed controls cover alphabet rollover, collision-budget
consumption, full nondefault source grammar and the real aggressive alias
adopter. Native execution, edit equivalence and oracle closure are not claimed
by these source-construction controls.
