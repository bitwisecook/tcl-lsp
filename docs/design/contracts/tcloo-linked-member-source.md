# Original TclOO linked-member source owner

`analyser::types::OriginalSourceLinkedMember` retains a genuine source class/member body, selected original `link` invocation, original list fields and the current original target method declaration. It supplies conditional source advice. It does not supply an object namespace, executing method frame, installed alias allocation or runtime dispatch.

Consumers use `original_source_linked_member_at` for a command head inside its actual original method scope. The query validates the current whole source/configuration/input, authenticates the selected helper's source schema, reads original native list children and selects the target through the original member ledger and retained member side. Bracket substitutions use the original `NativeWord` executable arenas. Ordinary operands, stale source, unknown link lists, unsupported provider geometry and ambiguous aliases decline. `ClassDef::linked_members` is a display inventory and cannot select a declaration.

`naming::native_oo_link_alias_geometry` and `native_oo_link_call_geometry` keep alias publication separate from call spelling. Stock C9 `link` concatenates the receiver namespace and `::` before parsing a relative alias: `{:shortcut target}` publishes `shortcut`, while calling `:shortcut` fails. Odd/interior separator runs follow the shared written-command parser. The target field is literal method data: `:target`, `::target` and the empty method name remain distinct. Symbolic receiver-relative geometry never constructs a substitute namespace.

Definition and hover consume the original target metadata. Rename initiation from an alias additionally requires the one-element coupled form and original editable target correspondence. Two-element descriptions retain separate alias and target fields even when both have the same bytes. `original_source_linked_member_reference_spans` gathers target fields and coupled call heads from the same current owner; it declines a partial edit set when decoding, missing ancestry or changed publication spelling prevents complete replacement. The rename hazard gate consumes that result. A readonly source extent alone cannot authorize an edit.

The retained experiments in `experiments/name-handling/tcloo-linked-source` cover original stock C Tcl 8.4.20–9.1.0 and the recorded latest local Jim build, including each provider's binary/library hashes, matching original Tcl library, exact scripts and stdout/stderr. Stock Tcl 8.6 has TclOO but no stock `link`; the captured Jim build has no TclOO. Tcllib `oo::util` and F5 implementation semantics require independent provider results. These stock captures certify C9 source geometry, not Native runtime closure or F5 event behavior. Tests consume the original C9 publication follow-on outputs and exercise current source ownership, literal target grammar, bracket heads, alias/target separation, stale input and unknown-list poisoning.
