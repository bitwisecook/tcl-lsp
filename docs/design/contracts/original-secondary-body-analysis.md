# Conditional original body analysis

`CompilationUnit::conditional_original_body_unit` provides readonly conditional CFG and lattice facts for an original child script. Its inputs are the actual compilation unit, an original function owned by that unit, the complete original parent command tokens, and the argument ordinal. It accepts no body text, offset, report name or namespace label.

The factory checks the complete CU/Module source, full lexer policy, actual Registry and metadata input, retained source owner, and function owner. `Lowerer::original_body_for_module` selects the original child source and its independently issued entry namespace before delegating original-body lowering. Missing, stale or foreign ownership returns unavailable. Original compiler, execution, Normal completion and effect admissions remain separate.

NestedScript purpose selects the child parser and CFG policy from the original function's complete configuration. The existing nested-source input projection retains the same actual profiles, command store and availability while issuing the child's configuration; the whole original input still guards parent and source-body ownership. The Script's retained namespace selects lookup; a synthetic function name does not. A secondary child's tokens can be analysed recursively using the same original CU function owner. The secondary function itself cannot masquerade as that original function.

The descriptive class roster from the configured signature producer is produced once by the configured signature scanner for the genuine CU build and retained in opaque `RetainedSourceClassFacts`. Primary and secondary analyses share the same immutable set, including empty classes. The shared selected signature producer runs once for every genuine CU, using the actual Registry grammar and original invocation inventory, including custom, directly renamed and directly aliased definers. Captured alias operands retain their separate source-position refusals; source spellings never schedule or classify a definer. Every projection checks source/channel/config/input/entry/store and the established immutable semantic Module owner. A pointer fast path follows the complete checks; fully equal descriptive source owners remain shareable without Native identity or physical lifetime. A synthetic unit explicitly retains absence or forwards the same original source owner; it cannot construct a class roster from names. The roster supplies descriptive class spellings, not Native class identity or constructor execution. `CompilationUnit::retained_source_class_names` provides the checked readonly projection shared by secondary-body analysis and Normal procedure-result inference. A missing class owner withdraws that query; an empty available set means the selected producer completed without class declarations. Normal result inference retains its independent actual implementation, metadata and completion guards.

Secondary lattice construction uses actual module mutation, trace and deferred-write facts. Its conditional analysis context carries no enclosing event descriptor, connection-entry names, parameter constants or entered worker/frame assumptions. Its inherited frame starts every place as may-bound; actual local stores, unsets and branch edges refine through the shared existence lattice. Unknown incoming presence does not make a place externally mutable. An explicit unknown-frame fallback prevents an empty child from selecting a procedure activation through its report name. A source-presence extension requires genuine point contexts rather than inferring absence from an empty parameter list. Registry collection and getter effect classification remain independent checks.

The iRules getter and collection scanners share `IrulesSourceQuery` for actual CU/Module/function configuration. Pairing analysis propagates unavailable side-body ownership; a withdrawn or dynamically selected body is not an empty collection inventory. Nested command substitutions use the same full policy and actual metadata generation. Positively tagged standalone analysis is an explicit separate fresh-source route using the caller's full policy.

Event-only diagnostics use the same checked source query to project the original `SourceIrulesEventBody` and its actual procedure. The actual CU function map, Module-issued descriptor, complete original declaration/body, full configuration and selected command store must agree. A function's report name does not classify an event or select its frame policy. An ordinary procedure named `::when::HTTP_REQUEST` remains ordinary. Unavailable ownership of a genuine event withdraws the whole event query, including pairing and mutation counts; it does not provide evidence that an event or mutation is absent. Hoist analysis receives only the descriptor's existing conditional source entry, without executing-event, worker, initialization epoch or TMM grants. Positively tagged standalone source retains its separate explicit ingress and still requires its actual selected event descriptor. For an original-source consumer, retain the actual CU and original function, pass the original vector and ordinal, and propagate unavailable results. Use a separately named standalone ingress only when the caller actually supplies standalone source. Do not reconstruct a Registry, namespace, child body or source owner from a report label.
