# Native LSP server release status

- #1657: The edit-ticket reservation already accounts for cancelled waiters. The request admission pool also now releases its permit while waiting for the edit barrier, so a stalled edit cannot consume all request slots and block an unrelated request. A deterministic transport regression covers the real barrier and checks that waiters resume once the edit completes. This limits the effect of an edit stall; it does not establish the cause of every reported wedge.
- #2021: The native server already has an exit watchdog for stdin EOF and the `exit` notification, with process-level regressions for both paths during a workspace scan. It does not independently monitor the client process if another process retains stdin. On source revision `9d9140a60`, `issue2021_exit_watchdog::eof_mid_scan_without_shutdown_forces_exit_within_grace` and `issue2021_exit_watchdog::shutdown_then_exit_mid_scan_forces_clean_exit_within_grace` both passed. Issue #2021 is externally authored; leave its closure to its author.
- #2295: The first workspace-symbol query now waits for scan completion, with cancellation, startup failure and shutdown handling. The previous bounded wait returned an empty result while package discovery was still running. The first-query regression passed on the earlier local revision `9dbfe27fa`, but took 52.19 seconds. A later instrumented run on base `a8a57e29d` also passed in 57.81 seconds; the trace identified installed Tcl/Tk index surveys across all five releases as a major startup cost. A two-worker native survey prototype is present but unverified; its correctness, cold and warm timings, and WASM serial fallback have not been tested. The current branch has not been reverified.

Verification: `cargo fmt --all -- --check` passed. The focused #1657 transport regression passed (1 test). Both #2021 end-to-end regressions passed. Before the readiness change the #2295 first-query regression failed twice. Clean post-change timing remains too slow for the existing 30-second workspace-scan barrier; startup performance remains unresolved.
