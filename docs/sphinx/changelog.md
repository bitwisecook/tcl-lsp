# Changelog

The authoritative changelog for `tcl-lsp` (the package `f5q`
ships inside) lives at
[CHANGELOG.md](https://github.com/bitwisecook/tcl-lsp/blob/main/CHANGELOG.md)
in the repository.  Each release lists every API surface change
under the **f5q** heading.

For the design-level history of how the Python API came together —
the polymorphic `q()` shape, the three plugin registries, the XDG
auto-loader — see the
[`f5q` plugin contract design doc](https://github.com/bitwisecook/tcl-lsp/blob/main/docs/design/f5-query-renderer-contract.md).
