[1mNAME[0m
       route - Configures a static route the generic message parser uses to
       route generic message protocol messages.

[1mMODULE[0m
       [1mltm message-routing generic[0m

[1mSYNTAX[0m
       Configure the [1mroute [22mcomponent within the [1mltm message-routing generic[0m
       module using the syntax shown in the following sections.

   [1mCREATE/MODIFY[0m
        create route [name]
        modify route [name]
          options:
            app-service [[string] | none]
            description [string]
            destination-address [string]
            peer-selection-mode [ sequential | ratio ]
            peers { [peer-name] }
            source-address [string]

        edit route [ [ [name] | [glob] | [regex] ] ... ]
          options:
            all-properties
            non-default-properties

        reset-stats route
        reset-stats route [ [ [name] | [glob] | [regex] ] ... ]

   [1mDISPLAY[0m
        list route
        list route [ [ [name] | [glob] | [regex] ] ... ]

   [1mDELETE[0m
        delete route [name]

[1mDESCRIPTION[0m
       You can use the [1mroute [22mcomponent to manage a generic message static
       route.

[1mEXAMPLES[0m
       [1mcreate route my_route[0m

       Creates a static route named [1mmy_route [22mthat uses a wildcard value for
       the [1msource-address [22mand [1mdestination-address [22mparameters. This acts as a
       default route.

       [1mcreate route my_route { destination-address helpdesk peers add { peer1[0m
       [1mpeer2 }[0m

       Creates a static route named [1mmy_route [22mthat contains two peers, [1mpeer1[0m
       and [1mpeer2[22m. Messages routed with a destination-address of [1mhelpdesk [22mare
       routed to a pool member contained in [1mpeer1 [22mor [1mpeer2[22m, based on the
       specified [1mpeer-selection-mode[22m.

[1mOPTIONS[0m
       [1mapp-service[0m
            Specifies the name of the application service to which the object
            belongs. The default value is [1mnone[22m. [1mNote: [22mIf the [1mstrict-updates[0m
            option is [1menabled [22mon the application service that owns the object,
            you cannot modify or delete the object. Only the application
            service can modify or delete the object.

       [1mdestination-address[0m
            Specifies the destination address of the route. If this parameter
            is not present, the generic message parser considers the
            [1mdestination-address [22mas a wildcard that matches all message
            destination addresses. The default value is [1mnone[22m.

       [1mdescription[0m
            User defined description.

       [1mpeer-selection-mode[0m
            Specifies the method the generic message parser uses to select a
            peer from the specified list of peers. The default value is
            [1msequential[22m.

            [1msequential[0m
                 Specifies that the generic message parser selects the first
                 peer in the list of peers. If the protocol retransmits the
                 message, the generic message parser uses another pool member
                 in the first peer. If all pool members in a peer are
                 unavailable, the generic message parser uses the next peer in
                 the list.

            [1mratio[0m
                 Specifies that the generic message parser selects a peer from
                 a list of peers based on the relative ratio values of each
                 peer. For example if three peers have ratios of [1m1[22m, [1m1[22m, and [1m2[22m,
                 the first 2 peers have a 25% (1/4) probability of being
                 selected and the third peer has a 50% (2/4) probability of
                 being selected.

       [1mpeers[0m
            Specifies a list of peers.

       [1msource-address[0m
            Specifies the source address of the route. If this parameter is
            not present, the generic message parser considers the [1msource-[0m
            [1maddress [22mas a wildcard that matches all message sources addresses.
            The default value is [1mnone[22m.
