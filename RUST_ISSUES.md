# RUST_ISSUES — origin/rust branch bug sweep

A deep review of the `origin/rust (tip 6820b3c)` branch (Rust workspace, editor integrations, build tooling) run on 2026-07-07. Each finding has its own file under [`rust-issues/`](rust-issues/): `RUST_ISSUE_<N>.md`.

**206 issues** — 5 critical, 42 high, 71 medium, 52 low, plus 36 backend-execution issues split into their own cross-priority section below.

Severity is the reviewer's estimate of user impact. **Verification** marks whether the reviewer confirmed the defect firsthand against the code (a representative sample across subsystems) or is relaying a review agent's report with its stated confidence. The full workspace test suite passes (11,249 tests); these are latent defects the tests don't cover, plus tooling/gate failures at the branch tip.

## How this was produced

Direct gate runs (fmt, clippy, `cargo test --workspace --all-features`, `cargo xtask` drift gates) plus subsystem code reviews covering the lexer/syntax tree, the compiler front-end, lowering, middle-end (CFG/SSA/SCCP/GVN/optimiser), analyser/diagnostics, the three execution backends (WASM runtime, bytecode VM, eBPF) and their parity, the command registry, the LSP server and its display/navigation/refactor providers, the BIG-IP model and f5-query/report/xc tooling, the CLIs, support crates, editor integrations, and build tooling/CI.

## Recurring root-cause themes

- **version-0 phi-join skip** — several dataflow passes (`sccp.rs:455`, `type_infer.rs:732`, `uri_split.rs:317`) drop the entry/live-in (parameter) operand from a phi merge, so a conditionally-assigned parameter folds to the assigned-arm constant. Miscompile in SCCP, wrong facts elsewhere.
- **fixed 2-byte backslash-escape slice** — `\<non-ASCII>` panics on a non-char-boundary slice in `semantic_tokens.rs:4597` and `subst_nocommands.rs:206` (the regex/regsub siblings are ASCII-guarded); related un-bounded multibyte slices in `certs.rs:96` and `cmd-core string.rs`.
- **decimal-only integer/index parsing** — runtime `lset`/`ledit`/`dict incr`/`lrepeat` and several helpers reject `0x`/`0o`/`end-N` forms the shared radix-aware core accepts, so the same index works via `lindex` but errors via `lset`.
- **prefix-abbreviation blind spots** — taint sources/sinks/sanitisers and a few option resolvers use exact subcommand match, so legal unique-prefix abbreviations (`string le`, `chan g`, `HTTP::cookie ins`) dodge classification.
- **signed-vs-unsigned / bounded-int semantics** — eBPF emits unsigned `DIV`/`MOD`/`RSH` for signed Tcl ints; the VM wraps `<<`/`**` past i128 where the runtime promotes to bignum.
- **retired-Python tooling leftovers** — a nonexistent `tooling/` tree breaks `make test-slow`, and stale `uv`/`pytest`/`.pyz` references linger in scripts, workflows, and the session hook.

## Backend execution — VM / runtime / WASM / eBPF (36)

All 36 backend-execution issues, split out across every priority (13 high, 13 medium, 10 low). These span the four execution backends — the bytecode VM, the WASM/tree-walking runtime, the eBPF pipeline, and their cross-backend parity — and are grouped here because several are large, individually-scoped features (TclOO / coroutines / a bignum integer tower in the VM, completion-code propagation through the WASM tier) rather than localised fixes. 29 fixed so far.

Partially addressed (not ticked): **008** — the VM half is done and then some: the bytecode VM now has coroutines (`coroutine`/`yield`/`yieldto`, incl. the `set arg [yield]` resume-value idiom via yieldable command substitution, and `coroutine … apply {lambda}`), a minimal event loop (`after`/`vwait`/`update` — the coroutine scheduler), and a **real shared-nothing `thread` package** (`thread::create`/`send`/`wait`/… + `tsv::*`, true OS-thread parallelism with `forbid(unsafe)` kept); `tcl_platform(threaded)` is now honest and the eBPF backend rejects concurrency primitives with a specific diagnostic. Coroutines are now **proven on wasm32** the plan's preferred way — the pure-data VM runs on `wasm32-unknown-unknown` (executed under Node in a skipping e2e test), so no asyncify is needed. The introspection/steering commands (`coroprobe`/`coroinject`/`::tcl::unsupported::corotype`) and multi-arg `yieldto` landed too, and **`yield`/`yieldto` now cross `eval` and `uplevel 0`** (run on the explicit stack via a transparent script frame), so the real C `tests/coroutine.test` runs the VM at **55/77** (3 skipped; the rest are the documented host-re-entry divergence + unimplemented `info frame`/`interp create`). Still open: wiring the VM as the *primary* wasm compile backend; `yield` across `subst`/`lmap`/`catch` (needs an inline-`subst` lowering / a collecting inline-`lmap` opcode); and the `thread::mutex`/`tpool` extras. **007** — **resolved**: `lpop`/`lremove`/`pid` were implemented and `exec`/`socket`/`load`/`fileevent`/`fcopy` error explicitly under WASM; the remaining `exit`/`time`/`timerate`/`tailcall`/`zlib` (plus `chan`/`coroinject`/`coroprobe`/`::tcl::unsupported::corotype`/`classvariable`) have now all gained real `register_builtin` handlers, so the **006** gate's `KNOWN_UNBACKED` allow-list is **empty** and `UNCLASSIFIED=0` — every core registry command is backed or explicitly classified. `zlib` drives DEFLATE/zlib/gzip through `flate2`'s pure-Rust `miniz_oxide` backend (wasm-clean, no C `libz`) with native checksums; `coroprobe`/`coroinject` extend the coroutine worker's rendezvous protocol; `exit` records its code and unwinds uncatchably rather than killing the embedding process. **014** — the WASM value-differential arm now honours leaf-command completion codes (so it covers abrupt-completion propagation, not just branch shape) and the `064` generator feeds far more of the language through both live arms; still outstanding are the genuinely new pairs (real linked-runtime WASM, eBPF, `tcl-vm`↔`runtime/rust`, `tclsh` cross-version) and error-message-text comparison. Verified throughout against a locally-built **tclsh 9.0.4** oracle plus the C `tests/*.test` suite run through the runtime.
